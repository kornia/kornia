`filter2d` and `filter3d` now accept a channels-last input, an input whose batch and channel axes are swapped in
memory, or an input expanded along the batch together with one kernel per sample (#5292). Previously such an input
raised torch's "view size is not compatible with input tensor's size and stride" when the batch and channel axes were
merged for the grouped convolution; a shared kernel and a contiguous input were unaffected, as was `fft_conv`. The
error reached `gaussian_blur2d` with a per-sample `sigma` on a channels-last image. The output values do not change.
