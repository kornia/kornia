`ssim` now filters a float32/float64 pair in float64 with a Gaussian window built in that dtype (#5574). Previously the
window was built in `img1.dtype` and each image was filtered in its own dtype, so the float64 result depended on the
argument order and missed the all-float64 value by up to 1.3e-4 on low-contrast images; both orders now equal it to
roundoff. Same-dtype pairs are unchanged, and `SSIM`, `ssim_loss` and `SSIMLoss` inherit the change.
