`KORNIA_CHECK_SAME_SIZE` checks that two tensors have the same size along a dimension, optionally accepting a size of 1 for the first, and `KORNIA_CHECK_SIZES` checks a tensor against sizes computed at run time, with `None` for a dimension of any size. Both build their error message only on failure. The `msg` of every `KORNIA_CHECK*` helper can also be a function without arguments, called only when the check fails: `KORNIA_CHECK(condition, lambda: f"...")`.
