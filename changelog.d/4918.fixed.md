`AugmentationSequential.show()` and `.save()` now work after a forward call that returns tensors (the default
`output_type="pt"`). The container cached the raw forward output, so `.show()` raised `RuntimeError: Can't call
numpy() on Tensor that requires grad` for an input that requires gradients, a `TypeError` for a CUDA or MPS one,
and `AttributeError: 'list' object has no attribute 'shape'` for a call with several data keys; it now caches the
augmented image alone, detached and on the CPU, like `ImageSequential` already did. A call whose data keys carry no
image caches nothing, and `ImageModule.save()` reports an empty cache with the same `ValueError` as `.show()`
instead of `AttributeError: 'NoneType' object has no attribute 'shape'`. Closes #4835.
