`kornia.metrics.confusion_matrix(normalized=True)` now normalizes each target row instead of each prediction column, as previous releases did. Non-empty rows sum approximately to one; empty rows remain zero. The `1e-6` denominator offset is unchanged. To reproduce the previous column normalization, compute `cm / (cm.sum(dim=1, keepdim=True) + 1e-6)` from the unnormalized matrix.
