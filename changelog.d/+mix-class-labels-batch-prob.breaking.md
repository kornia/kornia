`RandomMixUpV2` and `RandomCutMixV2` now apply `batch_prob` to class labels. When a replayed or custom `params` dict specifies a `batch_prob` that leaves some rows unmixed, those unselected rows now receive an unmixed label (their own class twice, with $\lambda = 0$) matching the unmixed image, instead of retaining a label that describes a mix with the drawn partner and weight.
