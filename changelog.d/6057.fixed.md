`ImageSequential` and `AugmentationSequential` with a `random_apply` range that includes 0, such as `(0, 2)`, `(0,)` or `0`, select none of their ordinary transformations when 0 is drawn; a mix augmentation in the chain may still be added, as for any empty selection. Previously such a call raised `RuntimeError: cannot sample n_sample <= 0 samples`, so a range that includes 0 crashed at random. A negative bound, or an upper bound below the lower one, now raises a `ValueError` naming `random_apply` when the container is constructed, instead of a raw `torch.multinomial` or `torch.randint` error at call time. Ranges that never draw 0 select exactly as before.
