`ObjectDetector.to_onnx` and `BoxFiltering.to_onnx` raise a `ValueError` when a `dynamic_axes` or `dynamic_shapes` argument makes the batch of a per-image-list export dynamic. Such an export has one graph output per traced image, so it used to succeed, declare a dynamic batch, and return the traced batch's detections at any other batch size: one image's detections for a batch of 3. The check reads the exported graph, so it covers every form of the two arguments, and an override that keeps the batch fixed, such as `torch.export.Dim.STATIC()` or a dynamic detection count only, still exports. Nothing is saved when it raises. `filter_as_zero=True`, and an RT-DETR detector built with `confidence_filtering=False`, export a dynamic batch as before.
