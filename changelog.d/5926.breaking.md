`XFeat()` now starts in evaluation mode, like `XFeat.from_pretrained()` and the reference implementation. It used to start in training mode, so `detectAndCompute`, `detectAndComputeDense` and the `match_*` methods normalised with batch statistics (each keypoint depended on the rest of the batch), updated the BatchNorm running statistics on every call, and a single match raised "Expected more than 1 value per channel when training". Call `.train()` to train.
