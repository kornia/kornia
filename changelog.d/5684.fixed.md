Unweighted 2D `fit_line` now fits float16 and bfloat16 points in float32, as the weighted 2D and D >= 3 paths already did, and returns the origin and direction in the input dtype. In float16 it used to return an infinite origin and a NaN direction when two coordinates differed by more than 65504 (for example points at x = -40000 and x = 40000), and a horizontal or NaN direction when a set of more than 65504 points overflowed the second moments. bfloat16 results change only by rounding.
