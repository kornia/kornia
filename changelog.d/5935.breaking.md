`ALIKED()` now starts in evaluation mode, like `ALIKED.from_pretrained()` and the reference implementation. It used to start in training mode, so `forward`, `forward_laf` and `extract_dense_map` normalised with batch statistics (each image's keypoints and descriptors depended on the rest of the batch), updated the BatchNorm running statistics on every call, and a single small image raised "Expected more than 1 value per channel when training". Call `.train()` to train.
