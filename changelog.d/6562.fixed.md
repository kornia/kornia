Speed up CUDA `fit_plane`, `solve_pnp_dlt`, and inference with `find_essential` for large point sets by reducing tall matrices with QR before SVD. Keep the existing derivative paths, CPU/MPS decomposition, and working precision.
On tall CUDA inputs with a NaN or Inf in a system reduced by QR, `solve_pnp_dlt` and `find_essential` return NaNs for the affected batch element. With value checks enabled, `fit_plane` raises `ValueCheckError`. These cases previously raised `LinAlgError`.
