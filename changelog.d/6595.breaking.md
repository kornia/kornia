`torch.compile(..., fullgraph=True)` around the trimmed `to_tensor` export of a `Boxes` built from a list now raises `Unsupported` before torch 2.10, because that export reads its padding mask with `nonzero`. It used to compile, on the lengths recorded when the object was built. With `capture_dynamic_output_shape_ops` and `capture_scalar_outputs` both set it compiles, and on torch 2.5 and 2.6 it returns wrong rows with no error, from a miscompile of `nonzero` in torch. `as_padded_sequence=True` and default `torch.compile` return the right rows on those versions, and from torch 2.10 the call works. `boxes[0][None].to_tensor()` on boxes built from a list now returns the trimmed list `boxes[0:1]` returns; it used to return one tensor that kept the padding rows as `[0, 0, 1, 1]`.
