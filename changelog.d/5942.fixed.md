`ImageStitcher.postprocess` now removes only the empty columns at the right edge of the mask, and keeps every column that has a covered pixel in any sample. It used to cut at the first empty column. A full-height gap in the mask, such as an invalid column in a `stitch_pair` mask or a pair of images that do not overlap, dropped every column after the gap. A first column with no covered pixel made it return the full width, empty columns included. Masks whose covered columns start at the first column and have no gap, such as those `forward` builds for overlapping images, give the same result as before.
