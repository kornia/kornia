`apply_colormap` and `ApplyColorMap` now select palette entry `floor(x * N)` for a value `x` in `[0, 1)`, and the last entry for `x = 1`, as matplotlib does, so all `N` colors cover an equal share of the range. Previously, with three or more colors, entry `i` was `ceil(x * (N - 2))` and `x = 1` selected the last entry, so the first color covered only `x <= 0` and the last only `x = 1`: with three, everything strictly between 0 and 1 selected the middle one. With two colors, every `x > 0` selected the second. Most outputs change color by up to one entry on large palettes and by more on small ones. With 256 colors, a `uint8` value `v` still selects entry `v`.
