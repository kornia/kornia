`apply_colormap` and `ApplyColorMap` now select palette entry `floor(x * N)` for a value `x` in `[0, 1]`, as matplotlib does, so all `N` colors cover an equal share of the range. Previously entry `i` was `ceil(x * (N - 2))`, which left the first color only for `x <= 0` and the last only for `x = 1`: with two colors, `0.01` selected the second, and with three, everything strictly between 0 and 1 selected the middle one. Most outputs change color by up to one entry on large palettes and by more on small ones. With 256 colors, a `uint8` value `v` still selects entry `v`.
