`copy.deepcopy`, pickle and `torch.save` of an augmentation whose range is an `nn.Parameter`, or of a container that holds one, now give a copy that owns its own parameter. `copy.deepcopy` no longer raises "Only Tensors created explicitly by the user (graph leaves) support the deepcopy protocol", and a pickled copy, whose parameter used to receive no gradient, now trains it. A copy draws like the original under the same seed, from the value the parameter had when it was copied, so `AveragedModel` can be built from such a module, but `update_parameters` does not reach its draws (#4428). `RandomBrightness`, `RandomContrast`, `RandomSaturation` and `RandomHue` now keep a parameter range as the parameter itself, on any device, in any dtype and as a 0-d half-width, instead of replacing it with a CPU copy, and still load their earlier checkpoints strictly. `RandomRGBShift` accepts a 0-d float64 limit.
