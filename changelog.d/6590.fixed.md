`PatchDominantGradientOrientation`, and so `LAFOrienter` and `SIFTFeature`, no longer give NaN gradients in float16 on textured patches, for the patch and for the smoothing weights. A float16 or bfloat16 patch is now computed in float32 with only the returned angle cast back, which also moves its angles toward the float64 result, and autocast no longer changes the result for a float32 patch.
