`XFeat.match_xfeat` matches a batch of image pairs: image `b` of `img1` with image `b` of `img2`. It runs each batch through `detectAndCompute` once and returns one `(N, 4)` tensor of `(x1, y1, x2, y2)` matches per pair, as `match_xfeat_star` does; a single pair still returns the tuple `(mkpts0, mkpts1)`. Before, a batch was extracted whole but only its first pair was matched and returned. On an Apple M1, matching two 640 x 480 pairs in one call is 1.26x faster on MPS than one call per pair, and 0.93x on CPU, where calling once per pair stays faster.
