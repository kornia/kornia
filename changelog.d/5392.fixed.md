`mean_iou_bbox` now computes float16 and bfloat16 boxes in float32 and returns the IoU in the box dtype. In float16 the IoU came out 0 or NaN once the two areas together overflowed: a 181 x 181 box against itself gave 0 and a 256 x 256 box NaN, so `mean_average_precision` scored a perfect float16 detection of a 512 x 512 box as 0 instead of 1. bfloat16 rounded the areas before the ratio (0.9766 instead of 0.9805 for a 200 x 200 and a 200 x 204 box). float32, float64 and integer boxes are unchanged.
