`transform_points` now raises `ValueError` when a matrix batch with several leading axes cannot align with the points' leading batch axes: an axis that is neither 1 nor the matching points axis, or more non-trailing-1 matrix axes than the points have batch axes. Previously such a batch was flattened and paired with the points by count, so `(2, 2, D+1, D+1)` matrices with `(4, N, D)` points used matrix `i` for point set `i`, and `(2, 2, D+1, D+1)` matrices with `(2, 4, N, D)` points paired the wrong sets. Reshape the matrices to `(B, D+1, D+1)` to keep the flat pairing.
