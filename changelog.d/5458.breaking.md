Nearest-neighbor resizing in `Resize`, `LongestMaxSize`, `SmallestMaxSize`, and slice-mode `RandomResizedCrop` now uses PyTorch's `nearest-exact` half-pixel sampling grid. Previously these augmentations used the legacy `floor(u * input_size / output_size)` grid, so nearest-resized images and masks can change. The transform matrix now follows the half-pixel grid and preserves the full image domain.
