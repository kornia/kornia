`LightGlue` built with complete learned weights (a `features` name, or a local `weights` file) now comes back in evaluation mode, like the other `kornia.feature` models built with pretrained weights. Missing derived buffers do not prevent evaluation mode, but checkpoints missing learned parameters leave the model in training mode, as does `LightGlue(features=None)` without weights. Its output does not depend on the mode.
