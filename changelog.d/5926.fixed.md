`SOLD2.match` now returns an int64 tensor when either set of segments is empty (it returned int32), and `XFeat.detectAndComputeDense` with `multiscale=True` no longer returns every cell of a scale whose share of a small positive `top_k` rounds down to 0: the budget is split `int(0.2 * top_k)` / the rest, so for a positive `top_k` the result never exceeds it (zero and negative values still keep every cell) (a default `top_k=4096` now yields 4096 keypoints instead of 4095 on images with enough cells).
