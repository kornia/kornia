`Affine` without `center` now builds its default centre at the parameters' batch size, so one parameter set warps every image of a batch, and `B` parameter sets warp one image into `(B, C, H, W)`, as they already did with `center` given. Both used to raise `ValueError: Inputs must have same batch size dimension`. A parameter batch that differs from the input batch, neither being 1, now raises a `ValueError` that names both batch sizes, with or without `center`, instead of a `RuntimeError` from a tensor expansion.
