`kornia.onnx.utils.ONNXLoader` caches every remote file under a path of its own. `HFONNXComunnityModelLoader.load_preprocessing`, which `DepthAnythingBuilder.build` calls, caches each repository's `preprocessor_config.json` beside its model in `<cache_dir>/<model_name>/`; every repository used to share `<hub_cache_dir>/preprocessor_config.json`, so a model built after another one could load the other model's preprocessing. `ONNXLoader.load_model("hf://<folder>/<a>/<b>")` caches `<a>/<b>.onnx` instead of `<a>.onnx` for every model under `<a>`. `load_model` and `load_config` cache a URL at `<scheme>/<host>/<directories of its path>/<file name>` under `cache_dir` or the default directory, with a `q-<hash>` directory before the file name when the URL has a query. A URL used to be cached under its last path component alone, query included, so two URLs that ended in the same file name, such as the `onnx/model.onnx` of two onnx-community repositories, shared one file. Files cached under the old names are neither reused nor moved, since they may hold another file's content: the affected configs and models are downloaded once more, and the old files, `<hub_cache_dir>/preprocessor_config.json` among them, can be deleted. The ONNX models of `HFONNXComunnityModelLoader` and `DepthAnythingBuilder`, and `hf://<folder>/<name>` models, keep their cache paths. `kornia.onnx.download.CachedDownloader.download` and `download_to_cache` accept a path without a directory part, which is a file in the working directory (or `cache_dir=""`), instead of raising `FileNotFoundError`. `kornia.io.get_sample_images` takes its download timeout from `KORNIA_DOWNLOAD_TIMEOUT` (30 s when it is unset), as kornia's other downloads do, instead of always using 30 s.
