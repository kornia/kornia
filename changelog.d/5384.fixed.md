`denormalize` and `Denormalize` check a `(C,)` mean or std against dimension 1, as `normalize` does, so every documented `(B, C, *)` rank works: rank-2 input no longer raises `IndexError`, and rank-3 or rank-5 input whose dimension -3 differs from C, including float statistics, is no longer rejected. A vector that matched dimension -3 instead of the channel count used to broadcast a 1-channel input to C channels; it now raises `ValueError`.
