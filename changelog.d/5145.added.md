`convert_sift_descriptor_layout` reorders SIFT descriptors between kornia's layout and OpenCV's, and `SIFTFeature` and `SIFTFeatureScaleSpace` take `descriptor_layout="opencv"` to return OpenCV's layout directly. `LightGlueMatcher("sift")` expects OpenCV's layout, which kornia's SIFT descriptors do not use by default, so request it or convert before matching: on Oxford Graf 1→4, `SIFTFeature` descriptors matched in kornia's layout gave 2 correct matches, and 497 in OpenCV's.
