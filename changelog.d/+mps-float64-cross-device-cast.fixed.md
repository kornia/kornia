On MPS with a float64 default dtype, `RandomAffine` and `RandomPerspective` return their sampled parameters, and a float64 CPU kernel passed to `filter2d`, `filter3d` or `fft_conv` with an MPS image gets its gradient. A copy between MPS and a float64 CPU tensor now casts on the CPU side: done in one step, it wrote zeros on torch 2.14 (every angle, scale, shear and translation 0, no perspective distortion, a zero kernel gradient) and raises on torch 2.15.
