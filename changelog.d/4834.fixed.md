`crop_by_boxes` and `crop_and_resize` now accept a box with a size-1 axis. Its vertices are collinear, so solving the perspective system from them returned a matrix of `NaN`; such a box now gets the matrix built from the box extents, with a plain translation on the size-1 axis. Boxes the solve already handled keep the same matrix. Resizing a size-1 axis to a larger size, or a larger axis down to size 1, still returns `NaN` (zeros with `mode="nearest"`), because no invertible matrix maps one onto the other.
