The tensor value checks of `adjust_gamma`, `adjust_contrast`, `solarize`, `marginal_pdf`, `histogram` and the vertex modes of `Boxes` used to be skipped on MPS; they now run there, as `torch._assert_async` from torch 2.13 and as a host read before. These checks, and those of `gaussian_blur2d`, `equalize`, `equalize3d`, `equalize_clahe` and the integer mask cast of `AugmentationSequential`, now follow one rule: they are skipped when checks are disabled with `disable_checks()` (they used to run regardless, except in `gaussian_blur2d`), and under functorch transforms, so `vmap` no longer fails on the missing batching rule of the assert. A tuple `sigma` of `gaussian_blur2d` is checked on the CPU whatever the default device; under a CUDA default device an invalid one used to trigger a device-side assert. `equalize` and `equalize3d` compile with TorchScript again.
