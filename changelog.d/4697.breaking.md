`AugmentationSequential` now rejects rank-4 image input when used with a 3D augmentation. Previously, rank-4 input was promoted as ``(C, D, H, W)``; this is ambiguous with the container's ``(B, C, H, W)`` image layout. To pass a single 3D volume explicitly, use ``unsqueeze(0)`` to add the batch dimension and provide input as ``(B, C, D, H, W)``. Bare 3D augmentations retain their rank-3 and rank-4 input promotion behavior.
