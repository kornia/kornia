`kornia.enhance.image_histogram2d` now places its automatic bin centers at the `n_bins` equal-width bin centers over `[min, max]`, `min + (i + 0.5) * (max - min) / n_bins`, whatever `bandwidth` is, so `bandwidth` only sets the kernel width. The centers used to be `min + (i + 0.5) * bandwidth`, so an explicit `bandwidth` other than `(max - min) / n_bins` moved the bins off `[min, max]` and `max` had no effect: four bins over `[0, 1]` with `bandwidth=0.5` had centers 0.25, 0.75, 1.25 and 1.75, and an image in `[0, 1]` left the last bin empty. Calls without `bandwidth` (or with `bandwidth=-1`) and calls with explicit `centers` are unchanged; only calls that pass `bandwidth` without `centers` give different histograms.
