`mutual_information_loss*` and `normalized_mutual_information_loss*` no longer return wrong values on MPS (Apple M1/M2) when the number of samples is between about 33k and 70k, for example a 184 x 184 image. The joint histogram now uses a matrix product with a contiguous transposed operand, which avoids a PyTorch MPS `bmm` bug (pytorch/pytorch#195163). Results on CPU and CUDA are unchanged.
