`Boxes` built from a list now records its padding per box, so item assignment and `index_put` no longer make the trimmed `to_tensor` export drop real boxes or keep padding rows, and a `VideoBoxes` merged with list-built boxes exports and draws masks, with the padding as invalid zero rows. A selection such as `boxes[0]` now shares its validity with the original exactly as long as it shares its coordinates: after `to`, `type` or an in-place transform of either, filtering or writing through one no longer blanks rows of the other. A padding row written to a dense `Boxes` now exports as zeros and draws no mask; it used to export as `[0, 0, 1, 1]` and draw one pixel. `boxes[0, 1:2]`, a tuple of index tensors and a `(B, N)` boolean mask now read a list-built `Boxes`; they used to raise `IndexError`. A row written behind a padding row now stays in the trimmed export; it used to be dropped. A `VideoBoxes` with `T = 1` built from or merged with list boxes now exports one `(B, 1, N, ...)` tensor; it used to return a ragged list.
