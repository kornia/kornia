`kornia_config.hub_cache_dir`, `hub_models_dir` and `hub_onnx_dir` default to an absolute per-user cache, `<torch.hub.get_dir()>/kornia` and its `models` and `onnx_models` subdirectories, which follows `TORCH_HOME`. They used to default to `.kornia_hub`, `.kornia_hub/models` and `.kornia_hub/onnx_models` relative to the working directory, so the ONNX Hub operators, onnx-community models and sample images were downloaded again in every new working directory and landed inside the user's project. Files already in a `.kornia_hub` directory are not moved: they are downloaded once more, and the old directory can be deleted. Set the three fields to keep the old location.
