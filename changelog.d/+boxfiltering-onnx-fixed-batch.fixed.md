`BoxFiltering.to_onnx` now fixes the batch at 1 when returning per-image detections, or honors an explicitly fixed `input_shape` batch. Previously, the graph declared a dynamic batch while returning only the traced batch's outputs, causing runtime errors or silently dropping images. An explicit dynamic batch now raises a `ValueError` pointing to `filter_as_zero=True`, which retains dynamic batch support through a single tensor output.
