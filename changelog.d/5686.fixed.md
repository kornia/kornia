`augmentation.CenterCrop`, `augmentation.CenterCrop3D` and `geometry.transform.CenterCrop2D` now raise `TypeError` when `size` is neither an int nor a tuple, and DeDoDe's `ConvRefiner` raises `ValueError` when a depthwise block's `out_dim` is not a multiple of its `in_dim`. Both used to raise a bare `Exception`; code that catches `Exception` is unaffected.
