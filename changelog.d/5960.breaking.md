`histogram_matching` with an empty template now raises a `ValueError` ("histogram_matching needs a non-empty template."); it used to raise an `IndexError` from inside the quantile computation. Passing `eps=` to `combine_tensor_patches` inside `torch.compile(fullgraph=True)` compiled before; `eps` now emits a `DeprecationWarning`, which makes that call fail with `Unsupported`, so drop `eps` from the call.
