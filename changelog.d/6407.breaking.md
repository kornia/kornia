`ScalePyramid(extra_levels=0)` now raises `ValueCheckError` (a `BaseError` and a `ValueError`), as does any `extra_levels` that is not a positive integer, including bools and floats. The error is raised even when the `KORNIA_CHECK` helpers are disabled (`python -O`, `KORNIA_CHECKS=0`, `disable_checks()`). Previously `extra_levels=0` was accepted and seeded every octave after the first from its least blurred level (index `-0` is level 0) instead of the level at twice the base blur, while `sigmas` still labelled that level with the base sigma, so the blur bookkeeping was wrong from octave 1 on. Python and NumPy integers, 0-d integer arrays and integer tensors are accepted and stored as `int`. Use `extra_levels >= 1`; the default `3`, and every `extra_levels >= 1`, build the same pyramid as before.
