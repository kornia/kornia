`ScalePyramid` now raises `ValueCheckError` when `extra_levels` is not a positive integer. With `extra_levels=0` it used to start every octave after the first from the least blurred level of the previous octave instead of the level at twice the base blur, while `sigmas` still labelled the new octave as if it started at the base blur; a negative value built fewer than `n_levels` levels per octave or crashed, and a bool was read as 0 or 1. Use `extra_levels=1` or more: every positive integer builds the same pyramid as before.
