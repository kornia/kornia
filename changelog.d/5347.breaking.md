`histogram`, `histogram2d` and `image_histogram2d` now reject a bandwidth that is zero, negative or not finite, and `image_histogram2d` also rejects `n_bins < 1` and an empty or non-finite `[min, max]` range when it builds the centers or the bandwidth from them. These inputs used to return NaNs or meaningless values, or a low-level error (`n_bins=0` raised `ZeroDivisionError`); `histogram` and `histogram2d` returned the same result for a negative bandwidth as for its absolute value. `histogram` and `histogram2d` now raise `RuntimeError` from an asynchronous check, like the other tensor-parameter checks in `kornia.enhance` (skipped on MPS); `image_histogram2d` raises `ValueError`. `image_histogram2d` now treats its documented `bandwidth=-1` as the automatic bandwidth, where it used to apply -1 as a literal negative bandwidth, and an empty `centers` tensor as automatic centers, where it used to return zero bins.
