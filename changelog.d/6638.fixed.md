`OnnxLightGlue` now runs on the GPU its `device` names: `device="cuda:1"` used to create the onnxruntime session on GPU 0 and bind the GPU-1 inputs as GPU-0 memory, which failed with an illegal memory access. Inputs on a different GPU from the matcher now raise `Wrong device`, even with `KORNIA_CHECKS=0`; a GPU index that torch does not see raises `ValueError` instead of silently creating a CPU session; and an index-less `"cuda"` means GPU 0 (`matcher.device` reports `cuda:0`).
