SVD no longer fails on MPS at 8192 elements or more. torch 2.14's MPS `linalg.svd` and
`linalg.svdvals` fail to build their Metal pipeline state object once an input holds 8192 elements
or more, whatever the per-matrix shape, so `find_fundamental`, `find_homography_dlt(..., solver="svd")`
and `solve_pnp_dlt` raised "Failed to created pipeline state object" at realistic batch sizes. Such
inputs are now decomposed on the CPU and moved back. `find_essential` still raises on MPS at any
batch size, because `run_5point` calls `torch.linalg.eigvals`, which has no MPS kernel.
