`LoFTR.forward` reduces runtime and peak memory by gathering only matched fine-level windows, selecting coarse
matches from row and column maxima, and using dense GEMMs for long-sequence linear attention. Outside float16,
dual softmax avoids PyTorch's slow `softmax(dim=1)` kernel and runs in place when no gradient is needed. Float16
retains native softmax, and temperature scaling follows the contraction to avoid overflow even under autocast.
Attention safely discards unused cross-head values and preserves zero outputs for padded queries at long sequence
lengths. The original float32 benchmark on 1024 px image pairs (IMC 2021 PhotoTourism validation, RTX 4090) measured
about 1.3x faster inference and 30 % less peak GPU memory; these timings predate the numerical fixes. Outputs may
change at the rounding level. The match selection itself differs from before only when a row of the confidence
matrix has two exactly equal maxima.
