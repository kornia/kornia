A tuple `forward` output of `ImageModule`, `ImageSequential` and the augmentation containers used
to come back as a list, and a one-element tuple as its bare element. It now keeps the tuple type
and its length. A caller that used the bare element of a one-element tuple output must index it:
`out = module(x)[0]`. A caller that already indexed a multi-element tuple output (`out[0]` for its
first element) needs no change.

A caller that relied on the list type of a multi-element tuple output (`isinstance(out, list)`,
`out.append`) must convert with `list(out)`. With `AugmentationSequential`, `output_type="numpy"` or
`"pil"` now raises `ValueError` when `data_keys` hold boxes, keypoints or labels: only images and
masks take the image conversion, since a box or keypoint tensor converted like an image is not a box
any more. A single such key used to come back converted as an image, and several keys raised
`TypeError`.
