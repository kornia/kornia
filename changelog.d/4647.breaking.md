`box_blur` and `BoxBlur` now default to `separable=True` instead of `False`, using two one-dimensional averaging passes. Both dense and separable floating-point paths use average pooling outside autocast (except where oneDNN's CPU convolution is faster), so results can differ by roundoff. `BoxBlur` no longer stores derived `kernel`, `kernel_x`, or `kernel_y` buffers: old checkpoints still load strictly, but their kernel values are ignored. Customizing these buffers no longer changes the filter; use `filter2d` or `filter2d_separable` for custom weights.
