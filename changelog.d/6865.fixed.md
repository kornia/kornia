`PinholeModel`, `KannalaBrandtK3` and `Orthographic` (and `CameraModel` with those types) apply batched `(B, P)` parameters per camera, as `BrownConradyModel`, `project_points` and `unproject_points` do. With `(B, N, 3)` points they aligned the parameters with the last point axis: `N == B` silently mapped each camera's points with another camera, `N == 1` projected to a `(B, B, 2)` result, and other `N` raised.
