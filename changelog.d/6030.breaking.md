`DepthEstimation` called on a `(B, 3, H, W)` tensor returns depth maps of shape `(B, 1, H, W)`, kornia's image layout; it returned `(B, H, W)`. A list of `(3, H, W)` images still returns `(1, H, W)` items. The graph exported by `to_onnx(include_pre_and_post_processor=True)` from a `DepthAnythingONNXBuilder` model takes an image that is already resized, such as `model.resize(image)`; it took an image of any size and squashed it to 518 x 518. The resize keeps the aspect ratio, so its output size depends on the input size, and it runs in torch before the graph.
