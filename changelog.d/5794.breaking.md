`kornia.contrib.histogram_matching` no longer extrapolates below the template minimum. When the template's darkest value covers a larger fraction of its pixels than the source's darkest value does (for example a template with clipped blacks), the source pixels whose quantile is below that fraction used to map below the template minimum, to negative intensities for a template whose minimum is 0; they now map to the template minimum, as in `skimage.exposure.match_histograms`. A constant template used to return NaN everywhere and now returns that constant.
