The `kornia.morphology` functions (`dilation`, `erosion`, `opening`, `closing`, `gradient`, `top_hat`, `bottom_hat`) now default to `engine="auto"`, which runs `"unfold"` on CPU and `"convolution"` on every other device. They previously defaulted to `"unfold"` everywhere. On MPS the eager `"convolution"` engine is several times faster and returns bitwise identical values; where a window has tied maxima the gradient can reach a different input pixel, and a float32 convolution that runs in reduced precision (CUDA with TF32) rounds the output. Pass `engine="unfold"` to keep the previous behaviour.
