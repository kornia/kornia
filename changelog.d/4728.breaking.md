The `kornia.morphology` functions (`dilation`, `erosion`, `opening`, `closing`, `gradient`, `top_hat`, `bottom_hat`) now default to `engine="auto"` instead of `"unfold"`. `"auto"` runs `"unfold"` on CUDA; off CUDA it runs the exact `"shift"` engine, except that a float32 or float64 CPU call recording a backward graph keeps `"unfold"`. For finite inputs the forward output remains bitwise identical to `"unfold"`, including mixed-dtype non-flat structuring elements. Gradients change only where `"shift"` is now selected: CPU float16/bfloat16 and MPS. Previously a window with tied maxima sent its whole gradient to one argmax; `"shift"` splits it across the tied inputs, so pixels that received exactly zero can now receive a fraction (the total is unchanged). Pass `engine="unfold"` to keep the previous gradient behaviour.
