`torch.export` of an `AugmentationSequential` holding a `Resize` with an integer `size`, a `LongestMaxSize` or a `SmallestMaxSize` no longer fails in the container's shape tracking. The integer side length is now converted to the aspect-preserving output size, as the eager path already does, so a later shape-dependent transform such as a resample-mode crop sees the shape it actually receives.
