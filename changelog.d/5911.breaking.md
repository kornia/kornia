`kornia.onnx.download.CachedDownloader.download_to_cache` takes `cache_dir` and `suffix` as keyword-only parameters and raises `TypeError` for any other keyword. `ONNXLoader.load_model` and `ONNXLoader.load_config` raise it for any keyword but `cache_dir`, whatever the model name or URL, and `HFONNXComunnityModelLoader.load_model` for any keyword. An unknown keyword, such as a misspelt `cachedir=`, used to be ignored, and the file was cached in the default directory. `download_to_cache` also raises `ValueError` for a `name` that is absolute or has a drive or an empty, `.` or `..` component, and for a `suffix` that adds a directory to the file name; so does `ONNXLoader.load_model` for an `hf://` name whose folder is `..`. Such names used to be joined to the cache directory as they were: `..` stored the file outside the cache directory, and an absolute name was stored below it on POSIX.
