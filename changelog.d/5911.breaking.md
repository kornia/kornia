`kornia.onnx.download.CachedDownloader.download_to_cache` takes `cache_dir` and `suffix` as keyword-only parameters and raises `TypeError` for any other keyword, also when it arrives through `ONNXLoader.load_model`, `ONNXLoader.load_config` or `HFONNXComunnityModelLoader.load_model`. An unknown keyword, such as a misspelt `cachedir=`, used to be ignored, and the file was cached in the default directory. It also raises `ValueError` for a `name` that is absolute or has an empty, `.` or `..` component. Such a name used to be joined to the cache directory as it was: `..` stored the file outside the cache directory, and an absolute name was stored below it on POSIX.
