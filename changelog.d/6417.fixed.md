`LightGlue` early stopping (`depth_confidence`) counts only the real keypoints on the static-length path of `LightGlue.compile`, so a padded pair stops at the same layer, with the same matches, as without padding; the padded positions used to count as unconfident points and delay the stop. Building a `LightGlue` model no longer switches PyTorch's process-wide FlashAttention setting (`torch.backends.cuda.enable_flash_sdp`) on or off: `flash` only selects the half-precision attention of CUDA tensors.
