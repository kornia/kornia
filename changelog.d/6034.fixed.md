The `kornia.morphology` operators run about 2x faster with less memory on CUDA, and with `engine="unfold"` on CPU, for a kernel without `structuring_element` when no gradient is recorded: the `unfold` engine masks the windows once and reduces them with `amax`/`amin`, without indices. Values are unchanged; as on every engine, an `erosion` window that ties `+0.0` with `-0.0` may return either zero. Calls that record gradients, forward-mode AD, `torch.func` transforms and traces keep the previous reduction.
