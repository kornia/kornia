`pixi run -e cuda install` now installs the locked PyTorch as a CUDA build. It used to reinstall torch from the CUDA
12.1 index, which stops at torch 2.5.1, so a CUDA development environment silently ran the oldest supported PyTorch and
moved several locked dependencies, such as triton and sympy, to other versions. The locked build needs an NVIDIA driver
from the R580 branch or newer and a Turing or newer GPU. Re-run this task on a `.venv` the old one created. Until then,
default-environment commands leave `import torch` failing: on `libcudnn.so.9` after `pixi run -e default install`, and
on `undefined symbol: ncclCommResume` after a `uv run` task such as `pixi run test-module`.
