`EdgeDetector.to_onnx` exports a detector whose post-processor returns a list with one map per image for a batch of one image, as `ObjectDetector.to_onnx` does for per-image detections. It used to declare a dynamic batch, and the TorchScript exporter (`dynamo=False`) turned the list into one graph output per traced image: the graph returned two maps for a batch of three images, and two maps, one of them empty, for a single image. The dynamo exporter failed on such a detector, and now exports it as well. A `dynamic_axes` or `dynamic_shapes` argument that makes the batch of such an export dynamic raises a `ValueError` after the export, before anything is saved. The default `ResizePostProcessor`, which the export replaces with one resize of the batch, and a post-processor that returns one tensor keep the dynamic batch.
