`RandomMotionBlur` now draws a ranged kernel size once per call and repeats it across `ksize_factor`, so the stored sizes match the shared size applied to the batch. Previously it drew a size per sample and used only one randomly selected entry. Angle and direction still follow `same_on_batch`. Fixed integer kernel sizes and replay of previously saved parameters are unchanged; seeded ranged calls with `same_on_batch=False` can produce different sizes and advance the random generator differently.
