`random_apply` with a count below the number of children and above the sum of `random_apply_weights`, or with a range that can draw a count above that sum which the children can fill, such as `PatchSequential` with `patchwise_apply=True`, now warns: it will stop repeating children in a future minor release. How often each child runs will change too: with weights `[0.9, 0.05, 0.05]` and `random_apply=2`, each 0.05 child runs in about 10% of calls today and will run in about 50%. Weights that sum to at least the count already give the new behavior.
