`adjust_gamma`, `AdjustGamma` and `RandomGamma` now return a zero gradient at black pixels (input `0`) for a gamma between 0 and 1, where `x ** gamma` has an infinite derivative. The gradient there was NaN on torch 2.14 and `inf` on earlier releases, so every image with a black pixel gave a non-finite input gradient. Output values are unchanged. A graph captured by `torch.jit.trace` keeps the plain power, as in 0.9.0, so tracing a module whose parameters feed `adjust_gamma` passes the trace check.
