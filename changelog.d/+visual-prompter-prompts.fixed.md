`VisualPrompter.predict(boxes=...)` uses a box prompt given as a tensor; it was dropped, and the prediction was the one without prompts. A `(1, K, 4)` box prompt is read as the K boxes of the image; for K > 1 it raised a tensor size mismatch, and box prompts for more than one image now raise a clear error instead of a batch size mismatch. `VisualPrompter` resizes the image with `Resize(img_size, side="long", align_corners=False, antialias=True)`, and keypoint and box prompts follow the same half-pixel map: the forward resize used `align_corners=True` while the masks are resized back with `align_corners=False`, which shifted the masks by up to 0.48 original pixels, and it did not antialias when it downscaled. `VisualPrompter.predict` and `Sam.forward` run in float16, bfloat16 and float64, with or without prompts: the SAM prompt encoder built its positional encoding in float32, and they raised `RuntimeError: expected m1 and m2 to have the same dtype`; it now computes it in the dtype of the model. `Sam.from_config` builds a custom ViT image encoder from `SamConfig(encoder_embed_dim=..., encoder_depth=..., encoder_num_heads=..., encoder_global_attn_indexes=...)` with `encoder_global_attn_indexes` a tuple, a list or an int; it raised `NotImplementedError` for a tuple or a list and `TypeError` for an int.
