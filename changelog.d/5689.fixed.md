`Canny` and `canny` with `hysteresis=True` can now be exported. Under `torch.export` the hysteresis loop is a `torch.while_loop`, so the exported graph repeats until nothing changes for any input, and the dynamo ONNX exporter writes it as an ONNX `Loop` from torch 2.11. Before, both exporters failed on the data-dependent loop. `Canny.ONNX_EXPORTABLE` is now `True`.
