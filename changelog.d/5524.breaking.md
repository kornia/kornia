`bilateral_blur`, `joint_bilateral_blur`, `BilateralBlur` and `JointBilateralBlur` used to return a wider dtype than a floating input when a tensor `sigma_space` or the `guidance` was wider, for example float64 for a float32 image with a float64 `sigma_space`. Both are now cast to the input's dtype, as a tensor `sigma_color` already was, so the output keeps the input's dtype.
