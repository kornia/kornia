`dice_loss` and `tversky_loss` now check that the target batch matches the prediction batch and raise `ValueError`
otherwise (#5544). Previously a `(1, H, W)` target for a `(B, C, H, W)` prediction made `tversky_loss` return the
loss of sample 0 alone and `dice_loss` broadcast the target, and a larger target batch averaged one prediction over
several targets or ended in a raw torch error.
