`correlate2d`, `convolve2d`, `correlate3d` and `convolve3d` are now listed in `kornia.filters.__all__`, so `from kornia.filters import *` brings them, and appear on the Filtering API page and in the API-surface inventory. They were already importable from `kornia.filters` by name, and equal `filter2d` / `filter3d` with `behaviour='corr'` / `'conv'`. The two 2-D docstrings now state the output shape for `padding='valid'`, and each of the four has an example that shows how correlation and convolution differ.
