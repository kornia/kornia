The blur-pool functions and modules export through the legacy ONNX exporter with dynamic batch, height and width. Edge-aware blur pooling combines its edge maps with a boolean OR instead of adding booleans, so it also exports with static shapes, and its dynamo export on torch 2.14 no longer gives a graph that onnxruntime rejects. `EdgeAwareBlurPool2D.forward` takes `epsilon=None` (meaning `1e-6`) by default, so a legacy export of the module no longer adds `epsilon` as a second graph input.
