`BoxFiltering.to_onnx()` without a `confidence_threshold` on the legacy (TorchScript) exporter used to export a second float64 input, `onnx::Cast_1`, for the threshold, which the caller fed. The graph now has the boxes as its only input and filters at the eager default of `0.0`, so feeding two inputs raises; build the filter with `confidence_threshold` to export a different threshold.
