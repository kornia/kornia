`XFeat.match_xfeat_star` finds the nearest neighbour of each second-image descriptor with a second matrix product and a
row-wise `argmax`, instead of an `argmax` down the columns of the similarity matrix, and frees the first matrix before
computing the second. XFeat* matching of a 640 x 480 pair is 1.26x faster on an Apple M1 CPU and 1.07-1.25x on an x86
i7-14700K, with identical matches. On CUDA (RTX 4090) the speed is unchanged, and the call's peak memory falls from 450
to 66 MiB at top_k=4096, because the column `argmax` allocated about six times the similarity matrix in scratch. MPS is
unchanged.
