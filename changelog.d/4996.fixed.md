The `shift` morphology engine (the default forward-only CPU engine) reads each kernel cell from a two-plane buffer through `index_select` instead of masking every shifted view with `masked_fill_`, and skips the offset addition when no `structuring_element` is given. Results are bitwise unchanged; forward-only `dilation` and `erosion` of a `B x 3 x 256 x 256` float32 image on CPU run 1.4 to 2.2 times faster than after #4818, within about 30 % of the speed before it.
