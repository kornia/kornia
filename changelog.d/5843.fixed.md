`So2.inverse()`, and so `Se2.inverse()`, now run on CPU float16 rotations, where they raised `NotImplementedError` because the CPU has no ComplexHalf reciprocal: the reciprocal is computed in complex64 and returned in the input dtype. On MPS, float16 inverses of rotations scaled far from unit length no longer return 0 or NaN, and inverses of unit rotations are more accurate.
