`dice_loss` and `DiceLoss` with `eps=0` no longer return a NaN loss (`'micro'`) or a NaN gradient (`'macro'`) for a sample whose pixels are all ignored, nor a NaN `'micro'` loss for a `weight` that is 0 for every class: such a sample enters the batch mean as loss 1 with a zero gradient, as it does at `eps > 0`. In float16 the `'micro'` gradient for an all-zero `weight` is now finite at the default `eps` too.
