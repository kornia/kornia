`RandomAutoContrast` emits a `DeprecationWarning` when `clip_output` is passed; the argument will be removed in a future release. It never changed the output, because `normalize_min_max` already returns values in `[0, 1]`. Its default clamp also zeroed the gradient wherever a channel's minimum or maximum was shared by several pixels on torch 2.14 and later. The clamp is gone, so the gradient no longer depends on the torch version.
