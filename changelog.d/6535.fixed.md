``kornia.feature.XFeat`` returns ordinary tensors now: its four inference methods run under `torch.no_grad()` instead of `torch.inference_mode()`, so `LightGlueMatcher("xfeat")` works in default grad mode on the outputs without a wrapper or a `.clone()`. Extraction costs about 3% more on CPU and every output stays bitwise identical. ``match_xfeat_star`` rejects a batch mismatch with the same ``BaseError`` its sibling raises.
