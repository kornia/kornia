`VideoSequential.inverse_keypoints` called with a raw `(B, T, N, 2)` tensor used to return it shaped `(T, B, N, 2)`, with the values still in `(B, T)` order; it now returns `(B, T, N, 2)`, as `transform_keypoints` does. The raw-tensor branches of `transform_keypoints`, `inverse_keypoints`, `transform_boxes` and `inverse_boxes` used to raise for zero keypoints or boxes, an empty video batch and a non-contiguous tensor; they now return the input's shape.
