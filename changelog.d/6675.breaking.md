`CornerHarris` with a number `k` now holds it as a Python `float`, not as a 0-dimensional float32 buffer. So
`harris.k.item()` raises `AttributeError`, and the `state_dict` no longer holds `k`, so a strict load into an older
kornia raises a missing-key `RuntimeError`. A tensor `k`, passed to the constructor, assigned to `harris.k` or
registered by a subclass, is still stored as a buffer, as before.
