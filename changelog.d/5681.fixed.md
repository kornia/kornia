`extract_patches_simple` and `extract_patches_from_pyramid` now sample the pixels a LAF describes. They built their grids in the corner-aligned frame (`2x / (W - 1) - 1`) and then sampled with `align_corners=False`, so a LAF centred on pixel `x` was read at `x * W / (W - 1) - 0.5`: up to half a pixel off, and stretched by `W / (W - 1)`. An axis-aligned LAF of scale `PS / 2` with odd `PS` now returns exactly the image crop, and a LAF covering a whole `W`-pixel axis has scale `W / 2`, where it used to be `(W - 1) / 2`. Descriptors, LAF orientations and AffNet shapes change for every pipeline that cuts patches from LAFs: `SIFTFeature` and `SIFTFeatureScaleSpace` with the `"patch"` backend, `HesAffNetHardNet`, `GFTTAffNetHardNet`, `KeyNetHardNet` and `KeyNetAffNetHardNet`. The `"pyramid"` SIFT backends are unchanged.
