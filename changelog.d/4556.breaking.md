The 3D warps and crops now honour `align_corners=False`. Previously the 3D coordinate normalization was always corner-aligned, so at `False` an identity warp did not reproduce its input and an integer box crop interpolated off-centre. `warp_perspective3d`, `homography_warp3d`, `affine3d`, `rotate3d`, `crop_and_resize3d`, `crop_by_boxes3d`, `RandomAffine3D`, `RandomRotation3D` and `RandomPerspective3D` default to `align_corners=False`, so their default outputs change; `warp_affine3d`, `center_crop3d` and `crop_by_transform_mat3d` change only when called with `align_corners=False`. Calls with `align_corners=True` and the augmentations' transform matrices are unchanged. Fixes #4503.
