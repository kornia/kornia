`filter2d`, `filter3d`, `filter2d_separable` and `fft_conv` now raise a `BaseError` naming both sizes when the kernel
batch is neither 1 nor the input batch (#5154). Previously `filter2d` and `filter3d` applied a kernel batch that
divides the input batch cyclically, sample `i` filtered with kernel `i % Bk`, and raised torch's view error for other
sizes; `fft_conv` broadcast one input sample over a batch of kernels, one output per kernel, where `filter2d` raised.
`gaussian_blur2d` with a tensor `sigma` of such a batch now raises through the same check. The documented
`(1, kH, kW)` and `(B, kH, kW)` kernels are unchanged.
