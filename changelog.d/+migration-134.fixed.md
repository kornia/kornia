`motion_from_essential_choose_solution` now returns the number of correspondences that pass the positive-depth test for the selected pose candidate (#4879). The returned tuple therefore contains the rotation, translation, triangulated 3D points, and a per-batch validity count. Previously, when no correspondence passed the depth test, all candidates had a score of zero and candidate 0 was selected silently with no way for callers to distinguish that case from a valid pose. Callers can now use the fourth return value to detect this condition: a count of `0` means that no point passed the positive-depth test for the selected candidate.
