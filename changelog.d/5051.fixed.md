`Keypoints.pad` and `Keypoints.unpad` accept the unbatched `(N, 2)` container the class documents and constructs. Both added the `(B, 1)` padding column to the `(N,)` coordinate view in place, which broadcast to `(1, N)` and raised `RuntimeError: output with shape [N] doesn't match the broadcast shape [1, N]`, so `RandomCrop` failed on `(N, 2)` keypoints with and without `padding`. They now shape the padding to the container, as `Boxes.pad` does since #4372, and match the singleton-batch result; an unbatched container carries one image, so a padding with more than one row is rejected. `padding_size` is also moved to the keypoints' device. Batched results are unchanged (closes #5021).
