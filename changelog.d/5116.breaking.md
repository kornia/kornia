`sampson_epipolar_distance`, `symmetrical_epipolar_distance`, `left_to_right_epipolar_distance`,
`right_to_left_epipolar_distance`, `point_line_distance`, `oneway_transfer_error` and `symmetric_transfer_error` no
longer add `eps` to their denominators or inside the square root; the singular cases, an epiline or line with
`a = b = 0` and a point that `H` maps to `w' = 0`, return `inf` instead (#4881). The values are now independent of the
scale of `F`, `H` or the line, `squared=False` returns exactly 0 for an exact match, with a zero gradient, and the CUDA
matmul and the CPU manual Sampson paths agree. Before, the same `F` at `‖F‖ = 1e-3` scored 90% lower than at
`‖F‖ = 1` (9.3e-6 relative there), an exact match scored `sqrt(eps) = 1e-4`, the two Sampson paths differed by that
scale-dependent amount, and a degenerate `F` returned `1e8` on CPU and `inf` on CUDA. The `eps` parameters are still
accepted and have no effect.
