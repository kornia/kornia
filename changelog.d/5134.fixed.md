`conv_soft_argmax2d` and `conv_soft_argmax3d` now take the softmax of every window over that window's own values
(#5020). Previously the exponent was shifted by the maximum of the whole map and `eps` was added to each window's
denominator, so a window far below that maximum, in units of `temperature`, collapsed to its centre with value 0 in
float32, float64 and bfloat16 and was NaN in float16; with `eps=0` such windows were NaN in every dtype. Those windows
now return the soft-argmax and value of their own window. Other windows move within precision: float64 coordinates
by up to 2.9e-6 and values by 4.3e-7 in 2D, 8.5e-9 in 3D; float32 by up to 2.9e-6 in 2D and 9.5e-7 in 3D; float16 and
bfloat16 by one to three ulp. `eps` is still accepted and is ignored. `conv_soft_argmax3d` runs in float16 and
bfloat16 on CPU, where it used to raise `NotImplementedError`. Memory grows by a factor of the window size (k*k in 2D,
k*k*k in 3D) of the output map.
