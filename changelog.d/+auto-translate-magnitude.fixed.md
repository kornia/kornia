`TranslateX` and `TranslateY` in `kornia.augmentation.auto.operations` now read a learned magnitude, or one passed to `forward_parameters`, as a fraction of the image width or height, the same as a magnitude sampled from `magnitude_range`. They used to translate by that value in pixels, so the default `TranslateX()` moved the image by 0.2 pixels. `RandAugment`, `TrivialAugment` and `AutoAugment` are unchanged.
