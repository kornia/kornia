`kornia.geometry.bbox.bbox_generator3d` now places each far corner at `start + size - 1`, so `infer_bbox_shape3d` reads back the requested width, height and depth and `bbox_to_mask3d` covers `width * height * depth` voxels, as with `bbox_generator` and `Boxes3D.from_tensor(..., mode="xyzwhd")`. Before, the far corner was at `start + size`, and every box measured one voxel larger than requested on each axis. Code that passed `size - 1` to work around this now gets boxes one voxel smaller on each axis and should pass `size`. `CropGenerator3D` did this and now passes `size`, so `RandomCrop3D` and the generator's `src` and `dst` boxes are unchanged.
