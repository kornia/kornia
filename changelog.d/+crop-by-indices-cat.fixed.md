`crop_by_indices` joins the per-row crops with one `torch.cat` when every row's slice already matches `size`, instead of a `copy_` per row (#4531): one copy kernel per batch instead of one per sample, with the same values and the same default memory format. `RandomCrop` (slice mode) and `CenterCrop2D` always take this path; rows that need `shape_compensation` still go through the per-row loop.
