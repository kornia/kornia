`safe_inverse_with_mask` and `safe_solve_with_mask` no longer turn the gradient NaN when one matrix in the batch is singular. Validity is decided on a detached pass and the invalid matrices are replaced by the identity before inverting or solving. An invalid row used to hold NaN in eager mode (a finite adjugate under tracing or export); it now holds the identity inverse (or `B` for the solve) in every mode. A float16 inverse that overflows is now reported invalid instead of `inf` with `mask=True`. `find_homography_dlt` and `fundamental_from_essential` still return NaN for degenerate input.
