`VideoSequential` with `same_on_frame=False` and a nested `ImageSequential` or `AugmentationSequential` now draws
the nested parameters per frame (#5513). Previously the nested container drew `B` rows for the `B * T` flattened
frames, so `VideoSequential(ImageSequential(RandomAffine(360, p=1.0)), same_on_frame=False)` raised a `grid_sampler`
batch-size error whenever a clip was selected; it now matches `nn.Sequential` on the flattened frames.
