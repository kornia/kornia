`kornia.geometry.transform.center_crop` and `center_crop3d` now start the crop at the integer pixel `int(src / 2 - dst / 2)`, as `CenterCrop2D`, `K.CenterCrop` and `K.CenterCrop3D` do, so they return a sub-image of the input. With an odd margin they used to start half a pixel off the grid, so `bilinear` blended neighbouring pixels and `nearest` duplicated rows or columns instead of returning the centre slice. For a `size` larger than the input with an odd margin, the extra padding pixel is now at the bottom/right.
