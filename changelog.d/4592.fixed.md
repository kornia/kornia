`kornia.filters.kernels.gaussian` no longer returns NaN when every sample underflows, which a small `sigma` (or `sigma = 0`) on a short window caused. It returns the unit-impulse limit instead, so `RandomGaussianIllumination` produces a finite image for every `sigma` its constructor accepts. Kernels with an odd window are bit-identical to before; an even window can differ in the last bit (half a float32 epsilon at worst over window sizes 1 to 31), because the nearest sample now sits a quarter-pixel away and that subtraction rounds. The impulse limit is differentiable: the gradient with respect to a tensor `sigma` is 0 there, the value of the continuous `sigma -> 0` limit, rather than NaN. An empty window still returns an empty kernel.
