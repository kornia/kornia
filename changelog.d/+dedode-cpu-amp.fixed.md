`DeDoDe()` with the default `amp_dtype=torch.float16` now runs `describe` and `forward` on CPU and MPS with float32 weights and images instead of raising `Input type (c10::Half) and bias type (float) should be the same`. `amp_dtype` is CUDA mixed precision in every component; the `G` descriptor's DINOv2 backbone is cast to it only for CUDA inputs, and on CPU and MPS stays in the dtype of its checkpoint (float32, where it used to be stored in `amp_dtype` right after construction). The CUDA path is unchanged. A `.half()` or `.bfloat16()` model with a different `amp_dtype` also runs there now.
