`draw_point2d`, `draw_rectangle` and `draw_convex_polygon` now reject a colour whose length is neither one nor the number of channels of the image, with the same check error `draw_point2d` already raised for a `(C, H, W)` image. The colour used to reach the assignment or the expansion and fail there with a raw `RuntimeError` from PyTorch, which says nothing about the colour or the image. The message names both numbers: the values the colour has and the channels the image has.
