`kornia.io.load_image` now raises a `ValueError` that names the file and keeps the decoder's reason, chained from the decoder's exception, when an image cannot be decoded (for example a truncated or corrupt PNG, JPEG or TIFF); it used to raise a bare `Exception` that did not name the file. A missing or unreadable file still raises the same `OSError` as before (`FileNotFoundError`, `PermissionError`).
