`DepthWarper.compute_subpixel_step` returns half a pixel of inverse depth at the image centre, which is `0.5 / (f * b)` for a rectified pair and agrees with `warp_grid`. It used to read the pixel position as a 3D point, so the step ignored the baseline and depended on the image size (`2.5e-06` instead of `0.01` for a 480x640 pair with `f = 500` and `b = 0.1`). Two cameras with no baseline now give `inf`.
