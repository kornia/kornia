Input checks no longer make a dynamic-shape `torch.compile` recompile for each new input size: their messages formatted tensor sizes or `int` arguments on every call, which specialized them. Over three sizes, `get_motion_kernel2d`, `motion_blur`, `fft_conv` with `padding="valid"`, `gaussian_blur2d` with a varying `kernel_size` and DeDoDe's `PatchEmbed` now compile one graph instead of three, `solve_pnp_dlt` two instead of four, `jpeg_codec_differentiable` four instead of eight (its quality-range message also read the tensor twice per call, which broke the graph and synchronized with the device in eager mode), and `ScaleSpaceDetector` 10 instead of 15. Size checks now raise `ShapeError` with both sizes, and the messages are no longer built on every call in eager mode.
