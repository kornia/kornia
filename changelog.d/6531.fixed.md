`LAFOrienter` rejects an image with more than one channel with a `ShapeError`, as `LAFAffineShapeEstimator` does. Such an image used to fail later with a reshape `RuntimeError`, or pass without error when there was no LAF to orient. `PatchAffineShapeEstimator` rejects a patch that is not `patch_size` pixels square, as its documentation requires. A `(B, 1, 1, patch_size)` or `(B, 1, patch_size, 1)` strip used to return the circle `(1, 0, 1)` whatever its content, `patch_size=1` weighted a patch of any size uniformly, and other sizes failed later with a broadcasting `RuntimeError`.
