`Rescale` works with `interpolation="nearest"`, `"nearest-exact"` and `"area"`. Previously its default `align_corners=True` was passed to `torch.nn.functional.interpolate`, which rejects any value but `None` for these modes, so every call that did not pass `align_corners=None` raised `ValueError`. `align_corners` now applies to the `bilinear` and `bicubic` modes only, whose results are unchanged; the other modes ignore it, an explicit `align_corners=True` included.
