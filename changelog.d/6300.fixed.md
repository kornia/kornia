`JPEGCodecDifferentiable` exported to ONNX with a dynamic height and width now follows the input size. The TorchScript exporter (`dynamo=False`) used to give a graph that, at any size but the traced one, returned an image of the traced size or wrong values, without an error. The dynamo exporter's graph used to fail in onnxruntime at any other padded size; on torch 2.14 it now follows the input size as well.
