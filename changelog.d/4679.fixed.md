`RandomMosaic` now respects `output_size` when transforming bounding boxes and no longer crashes with
`cropping_mode="resample"` when `output_size=None`. With an explicit `output_size`, both cropping modes now take an
unscaled `output_size` window of the composed canvas, so the boxes stay on their tiles; before, `"slice"` rescaled an
input-sized crop whenever every sample drew the same corner and zero-padded it otherwise. For a tensor box input,
when the gate selects only part of the batch the boxes are always returned as one dense tensor: an unselected sample
keeps its own boxes unchanged, followed by all-zero (zero-area) padding rows instead of the `[0, 0, 1, 1]` placeholder
that looked like a real box, and inputs with more than one box per sample no longer crash. Fixes #4652.
