`RandomMosaic` now respects `output_size` when transforming bounding boxes and no longer crashes with
`cropping_mode="resample"` when `output_size=None`. When the gate selects only part of the batch, the boxes are
always returned as one dense tensor: an unselected sample keeps its own boxes unchanged, followed by all-zero
(zero-area) padding rows instead of the `[0, 0, 1, 1]` placeholder that looked like a real box, and inputs with
more than one box per sample no longer crash. Fixes #4652.
