A misspelt name passed as `resample`, `padding_mode`, `border_type` or `data_keys`, or to the `.get` of a `kornia.constants` enum (`Resample`, `BorderType`, `SamplePadding`, `DType`, `DataKey`), and an unsupported `torch.dtype` passed to `DType.get`, now raise an error that names the value and lists the valid names. The error is a `ValueError`, like the one for an out-of-range integer, and still a `KeyError`. A value of the wrong type raises a `TypeError` that names the enum and the value, instead of listing every member of both enums.
