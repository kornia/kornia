`resize`, `Resize`, `rescale` and `Rescale` raise `ValueError` for `interpolation="linear"` and `"trilinear"`, with a message that names the supported modes, and so do `resize_to_be_divisible`, and `crop_by_indices` when a crop has to be resized. Their docstrings no longer list these two modes. Every input is resampled as a 4-D `(B, C, H, W)` batch, which `torch.nn.functional.interpolate` rejects for them, so these modes previously raised its raw `NotImplementedError` ("Got 4D input") for every input; only a target size with a zero side returned an empty tensor, and it now raises too. The other modes are unchanged.
