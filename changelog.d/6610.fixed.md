`MS_SSIMLoss` builds its Gaussian masks in float64 whenever it filters in float64 (float64 images or a float64
module). It used to cast masks built once in float32, so float64 results carried float32 rounding and differed from the
same loss constructed under a float64 default dtype. A float64 `MS_SSIMLoss` given float32 or half-precision images now
returns the float64 result rounded to the images' dtype, which can differ slightly from before; it is the only result
for float32 or half-precision inputs that changes.
