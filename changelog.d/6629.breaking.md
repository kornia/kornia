`normalize_homography`, `denormalize_homography`, `normalize_homography3d`, `denormalize_homography3d`, `AugmentationSequential.transform_matrix`, `ImageSequential.get_transformation_matrix` and `generate_patch_grid_from_normalized_LAF` used to return a half-precision result for float32 input inside a caller's `torch.autocast` region. They now return float32, computed in float32, so using such a result with a half-precision operand after the region needs an explicit cast.
