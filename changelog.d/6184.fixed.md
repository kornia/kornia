`BoxFiltering` with `classes_to_keep` now runs on boxes on another device than the class list, such as after `.to(device)` or `.cuda()`, instead of raising `RuntimeError: Expected all tensors to be on the same device`: `forward` moves the class list to the boxes' device, also one passed to `forward`. A `confidence_threshold` tensor of more than one element no longer raises `RuntimeError: Boolean value of Tensor with more than one value is ambiguous` in the constructor.
