`SpatialSoftArgmax2d.__repr__` now includes the opening parenthesis. `conv_soft_argmax3d` accepts an integer `stride` (matching the 2D form). `render_gaussian2d` rejects a non-positive `std` with a clear error instead of returning NaNs. `spatial_softmax2d` casts a tensor temperature to the floating dtype of the upcast logits, so an integer heatmap no longer truncates the temperature.
