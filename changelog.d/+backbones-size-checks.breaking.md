`VisionTransformer` and `SigLip2VisionEmbeddings`, and so `SigLip2VisionModel`, `SigLip2Model` and `PaliGemma`, raise `ValueError` for an input whose height and width are not both `image_size`, and `VisionTransformer` also for a channel count other than `in_channels`. An input whose patch count happened to fit the position table returned a result with misplaced position embeddings or dropped columns: for `VisionTransformer(image_size=224, patch_size=16)`, `(1, 3, 112, 448)` added the 14 x 14 positions to a 7 x 28 patch grid and `(1, 3, 224, 239)` dropped its last 15 columns. Other sizes and a channel mismatch raised `RuntimeError` inside the model, for example `(1, 3, 240, 240)` and `(1, 1, 224, 224)`; the `ValueError` of `VisionTransformer` fired only when both the size and the channel count were wrong.
