`RandomMosaic` now checks `padding_mode` at construction, in both cropping modes, and raises a `ValueError` that names the value and lists `constant`, `reflect` and `replicate` for anything else. Previously the constructor accepted any value: `cropping_mode="slice"` ignored it, and `cropping_mode="resample"` passed any other string to `grid_sample`, so `grid_sample`'s own names `zeros`, `border` and `reflection` worked (as `constant`, `replicate` and `reflect`) while any other value failed inside `forward` with torch's `grid_sample` error.
