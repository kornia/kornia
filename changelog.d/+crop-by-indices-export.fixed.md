`crop_by_indices` with `size` gave different crops under `torch.export`, `torch.onnx.export` and, on torch releases where `is_exporting()` is true inside `torch.compile` (2.9 and 2.11), under `torch.compile` too: the graph path resampled any box that is not exactly `size` pixels with `align_corners=True`, up to 0.98 off the eager crop. Export now uses the same gather as `torch.compile` for bilinear, bicubic and nearest interpolation, which matches the eager crop to float rounding.
