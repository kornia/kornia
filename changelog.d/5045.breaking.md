`strict_maxima_bonus` is deprecated and ignored in `conv_soft_argmax3d`, `ConvSoftArgmax3d`, `conv_quad_interp3d`, `ConvQuadInterp3d`, `iterative_quad_interp3d`, `IterativeQuadInterp3d` and `AdaptiveQuadInterp3d`. Previously the quad-interp functions and modules added `strict_maxima_bonus=10.0` by default to the returned value at every converged NMS maximum, and `conv_soft_argmax3d` scaled its values when given a positive bonus, incorrectly (#5018). Now no bonus is added: the returned values are the refined responses. The argument is still accepted, by keyword or in its 0.8.3 position, but it emits a `DeprecationWarning` and will be removed in a future release. The default refiners of `ScaleSpaceDetector` and `SIFTFeatureScaleSpace` already passed `strict_maxima_bonus=0.0`, so their detections are unchanged. Code that ranked the dense value map returned by these functions with `topk` and relied on the bonus to put strict maxima first should select candidates with a `nms3d(x, (3, 3, 3), mask_only=True)` mask instead.
