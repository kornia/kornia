The ONNX graph exported from a `BoxFiltering` without a `confidence_threshold` (and from detectors that contain one) has one input, the boxes. On the legacy exporter it used to have a second, float64 input `onnx::Cast_1` for the threshold, which was fixed at `0.1` in the trace, so it filtered at `0.1` instead of the eager default of `0.0`. Feeding two inputs to such a graph now raises. A filter with a `confidence_threshold` is unchanged.
