`AugmentationSequential` no longer builds the transformation matrix of each child on every call. Children whose matrix is lazy (flips, resizes, `RandomResizedCrop` in its default slice mode, and intensity augmentations) keep it lazy inside the container, and the chained matrix is built from the recorded calls when `.transform_matrix` is first read. Outputs, matrices, boxes, keypoints and masks are unchanged. On CUDA (RTX 4060 Laptop, torch 2.11) a `RandomResizedCrop`, `RandomHorizontalFlip`, `ColorJitter`, `RandomGrayscale`, `Normalize` pipeline on 32 images of 224x224 runs in 8.3 ms instead of 16.6 ms.
