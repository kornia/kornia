`AugmentationSequential` no longer builds the transformation matrix of each child on every call. Children whose matrix is lazy (flips, resizes, `RandomResizedCrop` in its default slice mode, and intensity augmentations) keep it lazy inside the container, and the chained matrix is built from the recorded calls when `.transform_matrix` is first read. Outputs, matrices, boxes, keypoints and masks are unchanged. On CUDA (Tesla T4, torch 2.11) a `RandomResizedCrop`, `RandomHorizontalFlip`, `ColorJitter`, `RandomGrayscale`, `Normalize` pipeline on 16 images of 224x224 takes 8.4 ms instead of 12.1 ms, and `RandomResizedCrop`, `RandomHorizontalFlip`, `RandomAffine` takes 7.0 ms instead of 10.2 ms (24-31% less time at batch 16 to 64).
