`warp_affine`, `warp_perspective`, `warp_affine3d` and `warp_perspective3d` with `align_corners=True` now sample a one-pixel source axis like a longer one, so positions outside it get `padding_mode`, instead of all repeating that pixel: a one-row image shifted down by one row comes back as zeros rather than unchanged. This changes the output on such inputs of `translate`, `rotate`, `scale`, `shear`, `affine`, `center_crop`, `center_crop3d`, `crop_by_transform_mat`, `CenterCrop2D(cropping_mode="resample")`, the augmentations built on them, and of `homography_warp`, `homography_warp3d` and `HomographyWarper` with a pixel homography. Images and volumes with every axis longer than one pixel are unchanged. This is a correctness fix, so it ships without a deprecation window.
