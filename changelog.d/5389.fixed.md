`kornia.onnx.download.CachedDownloader`, which `ONNXLoader`, `kornia.models.small_sr` and `kornia.contrib.super_resolution` download through, now uses `kornia.core.download`'s transfer: a server that stalls fails with `TimeoutError` after `KORNIA_DOWNLOAD_TIMEOUT` seconds (30 s when it is unset) instead of blocking forever, and a leading `~` in the cache directory or file path is expanded instead of creating a literal `~` directory.
