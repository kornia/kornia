`So3.matrix()`, `So3.adjoint()` and `So3 * p` now use the rotation of `q / |q|` for a non-unit quaternion, as `Quaternion.matrix()` does, instead of returning a scaled matrix that is not a rotation and scaling points by `|q|^2`. `Se3` and `NamedPose` inherit the fix. The quaternion is still stored as given, so an `nn.Parameter` stays registered; gradients with respect to it now pass through the normalisation.
