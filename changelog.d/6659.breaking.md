`kornia.augmentation.utils.override_parameters` now drops keys that are absent from the source dictionary by default (`if_none_exist="ignore"`) and raises `RuntimeError` for them with `if_none_exist="raise"`; it used to insert every override key. After `aug(x, ..., save_kwargs=True)`, `aug._params` records only parameter overrides: flag overrides and `save_kwargs` itself are no longer stored there. Replay with `params=aug._params` is unchanged, because it never applied a saved flag; pass flag overrides again on the replay call.
