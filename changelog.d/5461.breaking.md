`quaternion_exp_to_log` and `euler_from_quaternion` now normalize their input (#3953), matching `quaternion_to_rotation_matrix` and `quaternion_to_axis_angle`, so a rescaled quaternion gives the same result as the unit one. Unit inputs are unchanged to rounding; non-unit inputs that used to return a wrong value without error now return the value of the rotation they stand for. Before, `quaternion_exp_to_log([0.5, 0.5, 0, 0])` returned `[1.0471975511965976, 0, 0]`; it now returns `[0.7853981633974483, 0, 0]`. Before, a scalar part `w > 1` was clamped to `1`, so `quaternion_exp_to_log([2, 1, 0, 0])` returned the origin; it now returns `[0.4636476090008061, 0, 0]` (`[2, 0, 0, 0]` still returns the origin, the log of the identity). Before, `euler_from_quaternion` of `2 * q`, for the `q` of `(0.3, 0.7, 1.1)`, returned `[1.6560585860248003, 1.5707963267948966, 2.1048169977173687]`, a pitch of exactly `pi/2`; it now returns `(0.3, 0.7, 1.1)`. `quaternion_exp_to_log` computes the angle as `atan2(||v||, w)`, which needs no clamp and has a finite derivative at `w = +-1`.
