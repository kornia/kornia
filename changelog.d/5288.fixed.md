`Resize` with an integer size, `LongestMaxSize` and `SmallestMaxSize` now return an empty batch with the
resized spatial shape for a `(0, C, H, W)` input at `p=1` instead of raising `KeyError: 'output_size'`. With
`p < 1` the empty batch keeps the input's spatial shape, as it does for `Resize` with a tuple size and the other
shape-changing augmentations (#4429).
