`DepthWarper` and its functional form `depth_warp` sampled the destination patch half a pixel away from every projected pixel when `align_corners=False`, so an identity camera pair did not return its input. `warp_grid` normalized the projected pixels corner-aligned and then handed that grid to `grid_sample(align_corners=False)`, whose convention puts the pixel centres half a pixel inside the border; the grid is now rescaled to the flag's convention, and the default `align_corners=True` path is unchanged. A `height` or `width` of one is rescaled by `2.0` instead of `(size - 1) / size`, which is zero and would sample the lone pixel where the configured padding is expected.
