`ALIKED.extract_dense_map` takes a keyword-only `channels_last` flag, `False` by default, which returns the feature map
with the strides of `torch.channels_last`. `ALIKED.forward` and `ALIKED.forward_laf` use it for a float32 or float64
image on CPU, where normalising the map and sampling it for the descriptors are several times faster: the ALIKED-n16
forward is 1.18-1.36x faster on an Apple M1 and 1.30-1.57x on an x86 i7-14700K, from 1024 x 768 to 640 x 480. Keypoints,
scores and LAFs are unchanged, and float32 descriptors change by rounding (a few 1e-6). MPS and CUDA keep the previous
layout, which is faster there, as do float16 and bfloat16 on CPU, where `grid_sample` returns NaN for a channels-last
input.
