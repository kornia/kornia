`BoxFiltering.to_onnx` without `filter_as_zero` now exports a fixed batch: the batch of `input_shape`, else of `pseudo_shape`, else one image. With the TorchScript exporter (the default before torch 2.9), the graph used to declare a dynamic batch but return only the traced batch's per-image outputs: it ran correctly only at a batch of 5, failed in ONNX Runtime at smaller batches and silently dropped images at larger ones. The dynamo exporter failed. Pass `input_shape=[5, -1, 6]` to keep exporting for 5 images. An `input_shape` with a dynamic (`-1`) batch now raises a `ValueError` that points to `filter_as_zero=True`, which exports a batch of any size as one `(B, D, 6)` tensor.
