`BoxFiltering.to_onnx` now fixes the batch at 1 when returning per-image detections, or honors an explicitly fixed `input_shape` batch. Previously, the graph declared a dynamic batch while returning only the traced batch's outputs, causing runtime errors or silently dropping images. A dynamic batch, whether requested through `input_shape`, `dynamic_axes` or `dynamic_shapes`, now raises a `ValueError` pointing to `filter_as_zero=True`, which retains dynamic batch support through a single tensor output.
