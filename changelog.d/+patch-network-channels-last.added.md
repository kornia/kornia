`HardNet`, `HardNet8`, `SOSNet`, `TFeat`, `HyNet`, `LAFAffNetShapeEstimator` and `OriNet` now run their convolutions in channels-last memory layout on MPS (float32 and float16), which makes their convolution bodies 1.04-1.38x faster on an Apple M1. On CPU, all seven do the same for float32 when torch is built with oneDNN. `HardNet` used to convert on every CPU float32 build, including the macOS arm64 wheels, whose NNPACK convolutions take only the default layout, so the conversion was a copy that changed nothing. Outputs are unchanged.
