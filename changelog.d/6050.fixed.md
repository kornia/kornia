`ImageSequential` and `AugmentationSequential` accept integer, boolean and tensor `random_apply_weights`. Previously integer or boolean weights raised `RuntimeError: multinomial only supports floating-point dtypes` on every call, and a tensor of weights raised `RuntimeError: Boolean value of Tensor with more than one value is ambiguous` in the constructor. Non-floating weights are converted to the default floating dtype, and float weights keep their dtype, so existing selections are unchanged. Weights that are not one-dimensional now raise a `ValueError`; a nested float list used to be accepted and drew a selection per row, so `random_apply=1` applied more than one transformation.
