`KRt_from_projection` returns a proper rotation and the same `K`, `R`, `t` for every nonzero scale of `P`, including `-P` and a `P` scaled below the old `eps`, which is now unused (#4864). `triangulate_points` returns NaN for a correspondence at infinity instead of a finite point at a roundoff-set distance (#4865); `solver="cofactor"` normalises in the compute dtype, so pixel-scale float16 input is finite (#4863), and uses only the full-rank sub-system, NaN when both are rank-deficient, instead of a roundoff direction (#4900).
