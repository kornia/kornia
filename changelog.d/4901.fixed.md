`KRt_from_projection` returns a proper rotation and the same `K`, `R`, `t` for every nonzero scale of `P`, including `-P` and a `P` scaled below the old `eps`, which is now unused (#4864). `triangulate_points` returns NaN for a correspondence at infinity instead of a finite point at a roundoff-set distance (#4865); `solver="cofactor"` normalises in the compute dtype, so pixel-scale float16 input is finite (#4863), and returns the `svd` point instead of averaging two normalised sub-system null vectors: it refines the longest of the four through the adjugate of the DLT matrix. The average was up to 3.5 units off on a noise-free rectified pair and 144 on a pair rolled by 90 degrees, 3 to 6 units off on every point of a rectified, vertical or rolled pair with 0.5 px of noise (0.1 for `svd`), and a roundoff direction for zero baseline, which now gives NaN (#4900).
