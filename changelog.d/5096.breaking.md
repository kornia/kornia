Fixed `Similarity` rotation for non-square images in `ImageRegistrator`.

Previously, the rotation parameter was applied directly in the anisotropic normalized image coordinate system, causing the effective pixel-space rotation to depend on the image aspect ratio. `Similarity` now defines rotation in an isotropic coordinate frame and converts it using the image aspect ratio.

This changes the transform produced by `Similarity` when an image shape is set, so callers relying on the previous anisotropic rotation behavior should account for the corrected pixel-space convention.
