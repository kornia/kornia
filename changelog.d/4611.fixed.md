`equalize_clahe`, and so `RandomClahe`, builds every tile histogram with one `scatter_add_` instead of one `torch.histc` call per tile, which is 192 kernel launches for a 256x256 RGB image on the default 8x8 grid. The histograms and the output are bit-identical to before on CPU. On MPS the tile histogram now matches the CPU one for inputs marginally outside `[0, 1]` (for example `1.0000001` or `-1e-7`), which `torch.histc` on MPS counted and the CPU kernel skips.
