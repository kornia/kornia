`solve_cubic` now returns the real root of a cubic whose depressed form is `t^3 = 2R` with `R < 0` (for example `x^3 + 1`) instead of NaN. `solve_quartic` inherited the NaN through its cubic fallback and through its resolvent cubic: `x^4 - 3x^2 - 0.75` returned four NaNs instead of its real roots `±1.798`. The gradient of that `Q == 0` root also used to drop the root's dependence on `Q`, so for `x^3 - 1` the derivative with respect to the linear coefficient was 0 instead of -1/3; it now matches the implicit derivative.
