`FaceDetector` flips its input from RGB to BGR before YuNet, whose weights were trained on BGR images. It fed RGB, which found far fewer faces: on the docs figure `yunet.jpg` (input and output panels together, 421×1185) the detections rose from 221 to 600, and those scoring above 0.6 from 50 to 225. The input stays RGB in [0, 255]; the bare `YuNet` takes BGR in [0, 255]. `EdgeDetectorBuilder` feeds DexiNed BGR in [0, 255] minus the BGR mean `[103.939, 116.779, 123.68]`, the input it was trained on, instead of RGB minus the ImageNet RGB mean; on two street photos this changed 8–11 % of the `p > 0.5` edge decisions. The input stays RGB in [0, 1], and the state-dict keys of a saved `EdgeDetector` are unchanged. `DexiNed` (`kornia.models.dexined` and `kornia.filters.dexined`) no longer raises a `RuntimeError` about an in-place operation in backward; its forward output is unchanged. `FaceDetectorResult` checks the last dimension of its data, so `(15,)` and `(N, 15)` are accepted and a row of fewer than 15 values raises `ValueError`. It checked the first dimension, so a `(3, 15)` tensor raised and a `(20, 14)` one was accepted until `.score` raised `IndexError`.
