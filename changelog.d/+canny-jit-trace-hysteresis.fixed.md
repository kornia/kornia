`canny` and `Canny` with `hysteresis=True` under `torch.jit.trace`, and so the legacy TorchScript ONNX exporter (`torch.onnx.export(..., dynamo=False)`), no longer repeat the hysteresis round only as many times as the traced image needed. The loop is now a scripted function that the trace calls, so the traced graph and the exported ONNX `Loop` run until nothing changes on every input. Before, a longer edge chain than the traced one was cut short without an error, with only a `TracerWarning`. If TorchScript cannot compile the loop, a `RuntimeWarning` reports it.
