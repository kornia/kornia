`AugmentationSequential` now raises `NotImplementedError` on a keypoint or box data key (`keypoints`, `bbox`, `bbox_xyxy`, `bbox_xywh`) when the pipeline contains `RandomElasticTransform`, `RandomThinPlateSpline` or `RandomFisheye`, also inside a nested container or a `VideoSequential`. These warps have no transformation matrix, so the call used to return the keypoints and boxes unchanged while the image moved, and the labels no longer matched the image (#4420). The check reads the pipeline, not the sampled gates, so it also raises at `p=0` and when `random_apply` does not draw the warp; those calls used to succeed. Masks are unchanged: `RandomElasticTransform` warps them and the other two raise. A direct `RandomElasticTransform.apply_transform_box` call also raises instead of returning the boxes unchanged. Run keypoints and boxes through a pipeline without these warps.
