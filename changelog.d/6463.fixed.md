`kornia.geometry.transform.affine` reads an unbatched `(2, 3)` matrix as one matrix, `(1, 2, 3)`, that serves every image. With one image, `(C, H, W)` or `(1, C, H, W)`, it used to read the matrix's 2 rows as 2 matrices and return the image twice, as a batch of 2, with no error. With more images the matrix was already shared, and the result is unchanged. A matrix of any other rank raises `ShapeError` up front, a `ValueError` like the one `warp_affine` raised for it before.
