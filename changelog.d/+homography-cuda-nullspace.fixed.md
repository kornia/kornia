`find_homography_dlt` with the default `solver="lu"` computed the gauge null vector of a four-point sample with `torch.linalg.qr`, which has no batched CUDA kernel and factored a batch of 2048 minimal samples one matrix at a time in about 250 ms. On CUDA it now uses the batched SVD (about 1 ms), so `RANSAC("homography")` batches on GPU are up to 7x faster; CPU results are unchanged.
