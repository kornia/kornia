`RandomAffine3D` and `AffineGenerator3D` now draw a two-value `scale=(a, b)` once per sample and apply it to all three axes, as the docstring says and as the 2D `RandomAffine` does; each axis used to be drawn independently. The three-pair form `((a, b), (c, d), (e, f))` is unchanged. The random stream for a fixed seed changes for the two-value form: the scale consumes one draw instead of three, so the translations and shears drawn after it move.
