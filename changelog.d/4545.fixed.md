`KMeans.fit` no longer synchronises with the device once per cluster per iteration to update centroids; the update is now vectorised. This mainly benefits GPU backends where the per-cluster host syncs were expensive (e.g. MPS); on CPU the win is smaller and shrinks further at larger problem sizes, where the O(N·K·D) distance computation dominates. A fit that hits an empty cluster may now produce different (but equally valid) centers for the same seed, since the random reseed draws differ from before.
