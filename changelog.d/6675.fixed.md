`CornerHarris` with a number `k`, `SIFTDescriptor` and `PatchAffineShapeEstimator` now apply `k` and their Gaussian
windows to a float64 image exactly. They used the values built once in float32, so float64 results carried float32
rounding: `CornerHarris(0.04)` used `k = 0.03999999910593033`. `CornerHarris` keeps `k` in the same float32 buffer, so a
`k` loaded from a `state_dict` or assigned after construction still applies, in float64 too. A `gk` or `weighting`
buffer changed by hand is no longer used for a float64 patch. Float32 and half-precision results are unchanged. The
pooling weights of `SIFTDescriptor`, an `nn.Conv2d` parameter, are still built in float32.
