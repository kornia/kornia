`compute_padding` now pads an axis that is shorter than the window up to one full window. It used to return only the stride-alignment padding, which can leave the padded image smaller than the window: for a 4x6 image with an 8x8 window and stride 2 it returned `(0, 0, 0, 0)`, and `extract_tensor_patches(..., allow_auto_padding=True)` and `combine_tensor_patches(..., allow_auto_unpadding=True)` raised a `RuntimeError`. They now extract one window along such an axis and reconstruct the image. Results are unchanged wherever the old padding already fitted a window.
