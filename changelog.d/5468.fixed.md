`Boxes.compute_area`, `Boxes.transform_boxes` and `Boxes.translate` (and `Boxes3D.transform_boxes`) now accept non-contiguous box tensors, such as a `(B, N, 4, 2)` tensor made by transposing the batch and box axes. They used to raise `RuntimeError: view size is not compatible with input tensor's size and stride`; `compute_area` now returns the documented `(B, N)` areas.
