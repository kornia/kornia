`ScaleSpaceDetector` (`forward` and `detect`) and the patch descriptors `SIFTDescriptor`, `HardNet`, `HardNet8`, `HyNet`, `TFeat` and `SOSNet` accept an empty batch and return empty outputs of the documented shapes: responses `(0, N)` and LAFs `(0, N, 2, 3)` from the detector, descriptors `(0, D)` from the descriptors. So do `LocalFeature`, `SIFTFeatureScaleSpace` and `get_laf_descriptors` on zero images. They raised an unrelated reshape `RuntimeError`; an invalid input still raises what the same invalid non-empty input raises.
