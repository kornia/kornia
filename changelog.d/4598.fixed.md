`MKDDescriptor`'s `ExplicitSpacialEncoding` computes the spatial encoding with one matrix multiply instead of building a `(B, in_dims * d_emb, H, W)` product and summing it over the spatial dimensions. Descriptor values are unchanged and existing state dicts still load. `ExplicitSpacialEncoding` now raises `ValueError` for an input whose channel count differs from `in_dims`, as documented; its shape check could never fire.
