`elastic_transform2d` and `RandomElasticTransform` no longer clamp the displaced sampling grid to `[-1, 1]` before `grid_sample`, so `padding_mode` now applies to coordinates displaced outside the image. Previously `"zeros"`, the default of both, and `"reflection"` repeated the edge pixel there (`"zeros"` at half intensity, a quarter in the corners, with the default `align_corners=False` and bilinear sampling); now those samples are zero-padded or reflected as requested. Default outputs therefore change near the image border wherever the displacement points outward, and so do the gradients through those samples. `"border"` output is unchanged. This correctness fix ships without a deprecation window.
