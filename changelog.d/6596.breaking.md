`get_rotation_matrix2d`, `get_affine_matrix2d`, `get_affine_matrix3d` and `get_projective_transform` now return float32 for float32 inputs inside a `torch.autocast` region; they used to return the autocast dtype there. A matrix built in the region and used with a half-precision operand outside it now needs an explicit cast: outside the region, `warp_affine(half_image, matrix)` and `matrix @ half_matrix` used to run and now raise `RuntimeError`. Pass `matrix.to(half_image.dtype)` instead.
