`gaussian_blur2d` now rejects a tensor `sigma` whose batch is neither 1 nor the input batch at its entry with an error
that names `sigma`, before any kernel is built (#5169). Previously the mismatch surfaced from the kernel batch check of
`filter2d_separable` with a message about the kernel. `bilateral_blur` and `joint_bilateral_blur` now raise a kornia
error for a float `sigma_color` of 0 instead of Python's `ZeroDivisionError`, and `motion_blur`, `motion_blur3d`,
`get_motion_kernel2d` and `get_motion_kernel3d` now raise a kornia error for a `kernel_size` that is not an `int`
instead of torch's `TypeError`.
