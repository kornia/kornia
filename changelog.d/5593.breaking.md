`mean_average_precision` now averages only foreground classes with ground-truth objects across the evaluated images.
Previously, classes without ground truth contributed AP 0 and lowered mAP as `n_classes` increased. Their dictionary
entries are now `-1.0` (undefined, as in COCO), and mAP is `-1.0` when no foreground class has ground truth. Classes with
ground truth but no detections still contribute AP 0; class 0 remains excluded as background. Prediction and target
labels outside `0 <= label < n_classes`, previously silently skipped, now raise Kornia's `BaseError`.
