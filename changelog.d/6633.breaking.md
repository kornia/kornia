`load_state_dict` of a `_param_generator.*` range buffer now changes what the augmentation draws: it used to update the buffer and keep drawing from the constructor's range. A checkpoint that holds the same range as the module draws as before; one that holds a different range now draws from that range. A non-learnable loaded range outside the domain the class passes to its generator raises the constructor's `ValueError`; a learnable range is not validated after construction, so loading one outside the domain raises nothing and draws from it.
