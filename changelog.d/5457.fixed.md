On MPS with PyTorch before 2.7, `dilation`, `erosion` and the operators built on them (`opening`, `closing`, `gradient`, `top_hat`, `bottom_hat`) now propagate a NaN inside the window when they use the `shift` engine, which `engine="auto"` (the default) selects on MPS. They used to return a finite value there, because `torch.maximum` and `torch.minimum` ignore NaN on those versions.
