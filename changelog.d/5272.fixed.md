`kornia.onnx.download.CachedDownloader` keeps an absolute `cache_dir` absolute and caches only complete downloads, so a transfer that is cut short or interrupted is downloaded again on the next call. It used to store the file under a relative copy of the directory in the current working directory and to keep the partial file forever. A partial file already left in the cache by an earlier version is not detected: delete it once. A model cached under the misplaced relative directory is downloaded again once to the absolute one.
