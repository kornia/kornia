`invert` with the default `max_val` now keeps the shape of a 0-d input, as `Invert` does, instead of returning shape `(1,)`. `sharpness` now applies a `(1,)` factor to every image of a batch, as `adjust_brightness` and the other factor ops do, instead of raising. `ssim_loss` and `ssim3d_loss` now accept an int `max_val` as the same float. `MS_SSIMLoss` no longer warns about a target size mismatch when one image has a batch of 1; the loss is unchanged.
