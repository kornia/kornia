`kornia.core.download._url_list` now tells the caller of a `pathlib.Path` to load a local file with `torch.load`
(#5477). Previously it advised passing `path.as_uri()`, but a `file://` URL is cached by its base name like any other
URL, so a cache entry of that name was returned instead of the local file. `DexiNed.load_from_file` in
`kornia.filters` and `kornia.models` now reads a string that names an existing file with `torch.load` directly, and
the `load_state_dict_from_url` and `download_file_from_url` docstrings say how a `file://` URL is cached.
