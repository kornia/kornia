`ALIKED` compiles with `torch.compile` when the image size changes. The second size made Dynamo trace the sizes symbolically, and the padding of `extract_dense_map`, a modulo of the image size, reached the offset bound of `DeformableConv2d`, which inductor could not lower: the call raised `BackendCompilerFailed` (`TensorReferenceAnalysis has no attribute 'python_mod'`). The padding is now computed without a modulo and has the same value, so eager results are unchanged.
