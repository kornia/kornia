Fractional masks in `contrib.distance_transform` and `DistanceTransform` now use a piecewise differentiable generalized squared-distance transform: `sqrt(min(distance_squared - h * log(v)))`. Previously, a convolution cascade used a soft minimum, adding an isolated fractional source's `-h * log(v)` penalty to nearby distances only, within `kernel_size // 2`; it then reset reached pixels to 1. The new minimum carries source costs across the full image or volume and adds the penalty inside the square root, so fractional values and gradients change. A selected source can receive gradients from distant outputs; zero distances and nonpositive inputs have zero gradient, and ties select one minimizing source. Dense fractional pixels with `-h * log(v) < 1` select themselves; increase `h` to let stronger neighbours compete over longer distances. `kernel_size` remains accepted but no longer affects the result. `h` must be positive and finite and no longer has convolution-dependent bounds.
