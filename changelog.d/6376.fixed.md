`VideoKeypoints` indexing results support `to_tensor()`: `vk[0].to_tensor()` returns `(1, T, N, 2)`, where it used to raise `AttributeError` because the result had no `temporal_channel_size`. An `AugmentationSequential` with a `VideoSequential` now also accepts a `VideoKeypoints` object for its keypoints and returns one; it used to raise `TypeError` in `torch.is_floating_point`. `VideoSequential` hands its children frame-level keypoints, so augmenting video keypoints gives the same result as before.
