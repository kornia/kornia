`ImageSequential`, `AugmentationSequential` and `VideoSequential` no longer raise `IndexError: index 0 is out of
bounds for dimension 0 with size 0` on an empty batch when they contain a `CenterCrop`. A stage after an
always-applied `CenterCrop` records the crop size, as for a non-empty batch, so a later `CenterCrop` larger than
that size raises the same `AssertionError` as for a non-empty batch. With `p < 1` an empty batch keeps its input
size, as its forward pass does (#4429).
