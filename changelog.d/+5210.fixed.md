`ImageModule`, `ImageSequential` and the augmentation containers keep the container type of a
multi-output `forward`: a tuple stays a tuple and a one-element tuple stays a one-element tuple
with the helper features enabled, the same as with `disable_features = True`. A `forward` that
returns a dict, `None` or a Python scalar passes that output through instead of raising
`RuntimeError: Unexpected object ...` after the work has already run, and a list output converts
its elements for `output_type="numpy"` / `"pil"` like a tuple does instead of raising
`TypeError: Input type not supported`.
