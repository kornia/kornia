`warp_affine3d` raised `ValueError: Expected non-zero, positive output size` for an empty `(0, C, D, H, W)` batch, and so did everything built on it: `affine3d`, `rotate3d`, `crop_by_transform_mat3d`, `RandomAffine3D`, `RandomRotation3D`, `CenterCrop3D` and `RandomCrop3D`. They now return an empty batch of the requested output size, connected to both inputs for backward.
