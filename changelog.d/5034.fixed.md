`Hyperplane.through` no longer documents a two-point 2D form. That form never worked: `Hyperplane.through(p0, p1)` always raised a bare `Validation condition failed` (a 2D normal cannot be stored in a `Vector3`), and the unreachable code would have used the line direction as the normal. A two-point call now raises a `BaseError` saying that three points are required. The undocumented, unexported helper `kornia.geometry.plane.normalized`, used only by that code, is removed.
