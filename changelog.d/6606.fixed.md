`ScaleSpaceDetector` with kornia's own scale pyramid and response functions no longer gives a NaN image gradient for a float16 image with the default affine and orientation modules: it detects in float32 and returns its scores in float16, so its keypoints also land closer to the float32 ones. A custom pyramid or response function keeps float16 input, and `LAFOrienter` still gives a NaN gradient in float16.
