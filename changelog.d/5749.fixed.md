`LoFTR`'s coarse matching no longer returns a pair of masked cells as a match. With `mask0` / `mask1`, a pair whose two cells are both masked got the confidence `1 / (L * S)` from the two softmaxes (a fully masked row or column is uniform there, and all its other entries are exactly 0, so the pair was also a mutual nearest neighbour), and whenever `match_coarse.thr` was below `1 / (L * S)` it was returned with keypoints in the padding of both images. The confidence of a pair that involves a masked cell is now 0 after the softmaxes, and a zero confidence is never a match (a negative `thr` now behaves like `thr=0`), so a masked pair is not returned for any `thr` and `border_rm`.
