Speed up `RANSAC` with `local_optimization="lm"`, the default for homographies, fundamental and essential matrices. Hypothesis verification allocates fewer temporaries and, on CPU, is tiled at about a million residuals. The Levenberg–Marquardt stages, which run on the host for every input device, evaluate only the cost of their last trial instead of building an unused Jacobian, and the final refinement drops correspondences outside its inlier mask before building its equations. Five-point essential estimation evaluates its Newton correction with bounded cumulative products instead of general powers. Returned models can differ slightly, since rounding differences can change which refinement steps are accepted.
