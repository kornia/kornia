ONNX exports that declare a dynamic batch now run at every batch size. `to_onnx` traced them from a batch of 1, which `torch.export` specializes. On torch 2.9, the exported DexiNed edge detector and SAM image encoder kept that batch inside the graph, and ONNX Runtime rejected any other. `ResizePreProcessor` looped over the batch, so the loop unrolled at the traced size. On every torch release, the default exports of `EdgeDetector` and `SmallSR`, which include that pre-processor, returned one image's output for a batch of any size. `to_onnx` now traces each dynamic dimension at a size of at least 2, and `ResizePreProcessor` resizes a tensor batch in one call. An `ObjectDetector` whose post-processor returns a list of per-image detections, as the default confidence-filtered RT-DETR detector does, used to declare a dynamic batch and return the first image's detections for any batch. It is now exported for a batch of one image; build an RT-DETR detector with `confidence_filtering=False` to export a batch of any size.
