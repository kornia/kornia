`So3.log` (and through it `Se3.log`) returns the principal rotation vector, of norm at most π, whatever the sign of the stored quaternion. It used to return the long rotation `2π − θ` about the negated axis for a quaternion with a negative real part, which made `Se3.log` of a small rotation stored that way return a translation of order 1e6, and it rounded float32 rotations below 1e-4 rad to zero. (#4925)
