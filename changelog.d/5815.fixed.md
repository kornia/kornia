Mutual-information and normalized mutual-information losses now compute half-precision normalization, kernel weights, joint histograms and entropies in float32 and return the input dtype. float16 losses and gradients, NaN from about 184 × 184 pixels with the default kernel, are now finite, and both half dtypes lose the empty-bin bias on small images (12 × 20 seeded pair: float32 −2.662; float16 −2.547 → −2.662; bfloat16 −2.063 → −2.656). The histogram contraction now ignores autocast, so a float32 input inside an autocast region is computed and returned in float32; before, the contraction ran in the autocast dtype, which gave NaN under float16 autocast on large images and a bfloat16 result under CPU bfloat16 autocast. `entropies()` of a half-precision module returns float32. Cached reference modules keep the original dtype's constant-signal threshold and the same state dictionary keys.
