`load_image` raises the `OSError` subclass that `open()` raises (`FileNotFoundError`, `IsADirectoryError`, `PermissionError`), naming the path, for a missing, directory or unreadable file of every format. A JPEG path raised a bare `OSError` without the file name, so did a TIFF or WebP directory or unreadable file, and a directory or unreadable file with another suffix raised `ValueError` as an unsupported format.
