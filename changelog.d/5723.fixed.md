`SOLD2.match` no longer replaces the global `torch.diag` with a tensor, which made every later `torch.diag(...)` call in the process (including `MKDDescriptor(whitening=...)`) raise `TypeError`. `SOLD2(config=cfg)` no longer sets `use_descriptor = True` on the `DetectorCfg` it is given; it works on a copy. `WunschLineMatcher.needleman_wunsch` now allocates its table in the dtype of the scores; float64 scores used to raise an index_put dtype error. `WunschLineMatcher.match` now builds its sampling grid in the dtype of the line segments; a half-precision model used to raise `expected scalar type Half but found Float`.
