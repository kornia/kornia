`camtoworld_to_worldtocam_Rt`, `worldtocam_to_camtoworld_Rt`, `camtoworld_graphics_to_vision_4x4` and `camtoworld_vision_to_graphics_4x4` now return an integer result for integer input on CUDA, as they already did on the CPU. CUDA has no integer matrix multiplication, so these functions used to raise `NotImplementedError: "baddbmm_cuda" not implemented for 'Long'` (or the matching error for another integer dtype) there.
