LightGlue ONNX downloads (`download_onnx_from_url`, which `OnnxLightGlue` uses) now go through `kornia.core.download`. A server that stalls fails the attempt after `KORNIA_DOWNLOAD_TIMEOUT` seconds (30 s by default) instead of hanging, a transfer shorter than its `Content-Length` is no longer cached as the model, transient failures are retried, a `~` in `model_dir` is expanded, and `check_hash=True` also checks a file already in the cache and fetches it again on a mismatch. A failed download now raises `RuntimeError` naming the URL and the cache path, with the original error chained as its cause; it used to raise that error (`urllib.error.HTTPError`, `urllib.error.URLError`) directly.
