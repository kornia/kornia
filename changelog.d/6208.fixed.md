`quaternion_exp_to_log` returns the derivative of the log map at a quaternion with a zero vector part and `w > 0`, the identity included: `I / w` with respect to `(x, y, z)` and 0 with respect to `w`. It returned an all-zero gradient there, so a rotation fitted through the log map from the identity quaternion never moved. The only value that changes is that of a nonzero vector part whose norm underflows to 0 in the compute dtype (below about `1e-19` in float32), which now returns `v / w` instead of 0.
