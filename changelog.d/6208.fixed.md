`quaternion_exp_to_log` returns the derivative of the log map at a quaternion with a zero vector part and `w > 0`, the identity included: `I / w` with respect to `(x, y, z)` and 0 with respect to `w`. It returned an all-zero gradient there, so a rotation fitted through the log map from the identity quaternion never moved. For `w > 0` the `eps` clamp no longer applies, so a vector part shorter than `eps` gets its true log and gradient: `(1, 1e-9, 0, 0)` returns `1e-9` with `d log_x / dx = 1`, where it returned `1e-10` and `0.2`. For `w <= 0` the clamp is unchanged.
