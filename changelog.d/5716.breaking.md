`equalize_clahe` and `RandomClahe` now blend neighbouring tile lookup tables with weight steps of `1 / tile_size`, using OpenCV's pixel-coordinate convention, instead of `1 / (tile_size - 1)`. This changes interpolated output values in both the fast and differentiable paths. Border regions still clamp to the nearest tile along the border axis. LUT calculation and quantization are unchanged; Kornia's even-tile sizing and padding can still produce different results from OpenCV.
