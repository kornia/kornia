`DeDoDe()` with the default `amp_dtype=torch.float16` now runs `describe` and `forward` on CPU and MPS with float32 weights and images instead of raising `Input type (c10::Half) and bias type (float) should be the same`. `amp_dtype` is CUDA mixed precision in every component: the `G` descriptor's DINOv2 backbone is cast to it only for CUDA inputs, and on other devices follows the dtype of the input (a float32 backbone stays float32, a `.half()` model gets a half one), so a `.half()` or `.bfloat16()` model with a different `amp_dtype` also runs there now. The CUDA path casts on the host and then moves the backbone, as before; the one difference is that the cast happens at the first CUDA call instead of at construction, so about 0.6 GB more host memory is held in between.
