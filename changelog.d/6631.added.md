`build_laplacian_pyramid` gains `minimal_padding=True`, which pads a side only when `max_level` requires it and only to the next multiple of `2 ** (max_level - 1)`, so a 480x640 image at three levels stays 480x640 instead of becoming 512x1024; a side too small to reflect repeats its last row or column, or raises a clear error under `border_type="reflect"`. The current rule stays the default (`minimal_padding=None`) and now warns on the calls whose level shapes will change when a future minor release makes `minimal_padding=True` the default; `minimal_padding=False` keeps the current rule without the warning, and after that change keeps it for one more minor release with a deprecation warning. The values of each level change as well, even after cropping (up to 0.354 on a 5x8 image whose rows hold their index); an image rebuilt from the levels and cropped to the input size stays the same up to float rounding.
