`ImageModule` and `ImageSequential` (core and augmentation) `show()` and `save()` raise the documented `ValueError` before the first call instead of an `AttributeError`, and again after `disable_features = True`, which now clears the cached output instead of leaving the last image to be shown. An output that is not 3-D or 4-D gets one clear `ValueError` from both instead of an empty `ValueError` from `show()` and an `UnboundLocalError` from `save()`. `show()` keeps a unit height or width: a `(3, 1, 5)` image renders as a 5 x 1 RGB picture instead of a 3 x 5 grayscale one. `output_type="numpy"` turns a `bfloat16` output into a `float32` array instead of raising `TypeError`, and the cached output is no longer pickled with the module, so `torch.save(module)` no longer grows by the size of the last output (#5211).
