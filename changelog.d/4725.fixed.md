`ColorJiggle(order=...)` no longer turns off `torch.distributions` argument validation for the rest of the process. Its eager `torch.cond` dispatch entered Dynamo, whose one-time setup disables that validation globally; the caller's setting is now restored. A fixed `order` also no longer raises `torch.cond requires dynamo support` where Dynamo is unavailable (torch 2.5.1 on Python 3.13); it uses the Python dispatch there.
