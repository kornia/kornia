`box_blur` and `BoxBlur` now default to `separable=True`, applying two 1D convolutions instead of one 2D convolution. This accelerates many CPU and large-kernel workloads, but small-kernel workloads can be slower and floating-point results can differ, particularly in half precision. Pass `separable=False` to retain the previous path, including when loading old default `BoxBlur` state dictionaries with a `kernel` buffer. The flagship filters benchmark compares both paths explicitly.
