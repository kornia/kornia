`SOLD2_detector` neither builds nor runs the descriptor head of the SOLD2 network, whose output it never used: the same junctions, heatmaps and line segments, 7 % fewer parameters, and a forward about 13 % faster on CPU at 512 x 512. Weights saved with the head still load. `SOLD2_detector` also downloads the pretrained checkpoint from the Hugging Face mirror with a fallback, the same file `SOLD2` uses, instead of a single ETH URL, so the two classes share one cached copy.
