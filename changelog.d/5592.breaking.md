`RandomTransplantation` inside `AugmentationSequential` now returns a batched `(B, H, W)` mask as `(B, 1, H, W)`, like every other child without `keepdim=True`. Previously it returned the mask as given, so a pipeline whose only child is the transplant, or whose transplant runs after a child with `keepdim=True`, returned `(B, H, W)`. With the container's `keepdim=True` the mask stays `(B, H, W)`. A mask of the wrong rank is now refused with "Every segmentation mask must have one fewer dimension ... than the image" instead of "Every image input must have one additional dimension ...".
