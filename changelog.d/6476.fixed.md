`transform_points` aligns a matrix batch with several leading axes, `(B1, ..., Bk, D+1, D+1)`, with the first `k` batch axes of the points, broadcasting a size-1 matrix axis. Such a batch used to be flattened and repeated by count, so `(1, 2)` matrices with `(3, 2, N, D)` points or `(2, 2)` matrices with `(2, 4, N, D)` points paired the wrong matrices with the points without an error. Trailing size-1 matrix axes, as in `(B, 1, 1, D+1, D+1)` with `(B, H, W, D)` points, still broadcast over the remaining point axes, and single-axis `(B, D+1, D+1)` and unbatched matrices behave as before.
