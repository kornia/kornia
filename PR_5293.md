# Pull request: fix nearest resize augmentation matrices

Closes #5293

## Summary

- Use PyTorch's `nearest-exact` half-pixel sampling for nearest `Resize`, `LongestMaxSize`, `SmallestMaxSize`, and slice-mode `RandomResizedCrop`.
- Record the matching half-pixel transform matrix, keeping source image edges within the mapped output domain and allowing inverse resizing to use the correct geometry.
- Cover the full matrix for a non-square 7x7 to 14x21 resize, nearest inverse round-trip, empty batches, and slice-mode output equivalence.

This changes nearest-resized values: the previous implementation used legacy `floor(u * input_size / output_size)` sampling. See `changelog.d/5458.breaking.md`.
