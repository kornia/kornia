Linear RGB
==========

.. currentmodule:: kornia.color

Convert sRGB to linear RGB with :func:`rgb_to_linear_rgb` before :func:`~kornia.color.rgb_to_xyz`, and back with
:func:`linear_rgb_to_rgb`.
