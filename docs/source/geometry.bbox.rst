kornia.geometry.bbox
====================

.. meta::
   :description: The kornia.geometry.bbox module in Kornia provides useful functions for manipulating 2D and 3D bounding boxes. It includes tools for creating, transforming, and operating on bounding boxes, making it easier to handle spatial data in computer vision tasks.

Functional API for 2D and 3D bounding boxes represented as corner tensors of shape :math:`(B, 4, 2)` and :math:`(B, 8, 3)`.
For an object-oriented interface with format conversions, see :doc:`geometry.boxes`.
