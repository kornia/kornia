kornia.geometry.boxes
=====================

.. meta::
   :description: The kornia.geometry.boxes module in Kornia provides essential functions for manipulating 2D and 3D bounding boxes. It offers utilities for the creation, transformation, and handling of bounding boxes, which are crucial for spatial data processing in computer vision applications.

Object-oriented API for 2D and 3D bounding boxes: the :class:`~kornia.geometry.boxes.Boxes` and
:class:`~kornia.geometry.boxes.Boxes3D` classes wrap a tensor of boxes and provide format conversions
(``xyxy``, ``xywh``, vertices), transformations and padding.
